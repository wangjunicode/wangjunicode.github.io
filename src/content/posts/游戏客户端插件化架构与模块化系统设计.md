## 概述

随着游戏项目规模的持续膨胀，单体式架构的维护成本呈指数级增长。插件化架构（Plugin Architecture）通过将功能拆分为独立模块，实现了关注点分离、并行开发、按需加载和运行时扩展等关键能力。本文从游戏客户端的实际工程需求出发，系统性地阐述插件化架构的设计原理、核心机制与落地实践。

## 为什么游戏客户端需要插件化架构

### 单体架构的痛点

在传统单体式游戏客户端中，所有功能模块直接耦合在同一个进程中：

- **编译耦合**：任何模块的修改都触发全量编译，大型项目单次编译耗时可达10-30分钟
- **团队冲突**：多人同时修改同一代码区域，合并冲突频繁
- **测试困难**：模块间依赖复杂，难以进行独立单元测试
- **部署僵化**：修复一个Bug需要发布整个客户端包体
- **技术债务**：缺乏清晰的模块边界，架构持续腐化

### 插件化架构的核心收益

| 维度 | 单体架构 | 插件化架构 |
|------|---------|-----------|
| 编译效率 | 全量编译 | 增量编译，仅编译变更插件 |
| 团队协作 | 代码冲突频繁 | 接口契约隔离，并行开发 |
| 可测试性 | 依赖全局状态 | 可独立Mock测试 |
| 部署灵活性 | 全量发布 | 按需加载，热更新 |
| 代码复用 | 跨项目复用困难 | 插件可独立分发复用 |

## 插件化架构的核心设计要素

一个成熟的游戏客户端插件化架构需要解决以下核心问题：

1. **插件定义与生命周期**：什么是插件？它如何被创建、初始化、运行和销毁？
2. **依赖管理**：插件A依赖插件B的某个服务，如何声明和解析这种依赖？
3. **通信机制**：插件之间如何解耦通信？
4. **加载与卸载**：如何实现运行时的动态加载和卸载？
5. **版本兼容**：不同版本的插件如何共存和升级？

## 插件系统的分层架构

```
┌─────────────────────────────────────────────┐
│              应用层 (Application)             │
│   UI框架 │ 战斗系统 │ 网络层 │ 资源管理 ...   │
├─────────────────────────────────────────────┤
│             插件管理层 (Plugin Manager)        │
│  加载 │ 卸载 │ 依赖解析 │ 生命周期 │ 通信总线  │
├─────────────────────────────────────────────┤
│             插件契约层 (Plugin Contract)       │
│  IPlugin │ IPluginService │ 元数据 │ 版本     │
├─────────────────────────────────────────────┤
│             核心运行时 (Core Runtime)          │
│   引擎抽象 │ 基础工具 │ 通用数据结构           │
└─────────────────────────────────────────────┘
```

### 3. 插件管理层（Plugin Manager）

插件管理层的核心职责是管理插件的全生命周期，包括发现、加载、依赖解析、启动、停止和卸载。

```csharp
public class PluginManager : IPluginManager
{
    private readonly Dictionary<string, PluginInstance> _plugins = new();
    private readonly Dictionary<string, object> _globalServices = new();
    private readonly EventBus _eventBus = new();
    private readonly IEngineAdapter _engine;
    private readonly AssemblyLoader _assemblyLoader;
    
    public PluginManager(IEngineAdapter engine)
    {
        _engine = engine;
        _assemblyLoader = new AssemblyLoader();
    }
    
    /// <summary>
    /// 从指定目录扫描并加载所有插件
    /// </summary>
    public async Task LoadAllPluginsAsync(string pluginsDirectory)
    {
        // 1. 扫描插件程序集
        var pluginAssemblies = _assemblyLoader.ScanDirectory(pluginsDirectory);
        
        // 2. 解析插件元数据
        var pluginDescriptors = new List<PluginDescriptor>();
        foreach (var assembly in pluginAssemblies)
        {
            var descriptor = ParsePluginDescriptor(assembly);
            if (descriptor != null)
                pluginDescriptors.Add(descriptor);
        }
        
        // 3. 拓扑排序 - 按依赖关系排序
        var sorted = TopologicalSort(pluginDescriptors);
        
        // 4. 按序初始化
        var context = CreateGlobalContext();
        foreach (var descriptor in sorted)
        {
            await LoadPluginAsync(descriptor, context);
        }
    }
    
    private async Task LoadPluginAsync(PluginDescriptor descriptor, IPluginContext context)
    {
        // 验证依赖是否已加载
        foreach (var depId in descriptor.Metadata.Dependencies)
        {
            if (!_plugins.ContainsKey(depId))
                throw new PluginException($"依赖插件 {depId} 未加载");
        }
        
        // 创建插件实例
        var plugin = (IPlugin)Activator.CreateInstance(descriptor.PluginType);
        var pluginContext = new PluginContext(descriptor.Metadata.Id, context);
        
        // 初始化
        var success = await plugin.InitializeAsync(pluginContext);
        if (!success)
        {
            _engine.Logger.Warn($"插件 {descriptor.Metadata.Name} 初始化失败");
            return;
        }
        
        _plugins[descriptor.Metadata.Id] = new PluginInstance
        {
            Descriptor = descriptor,
            Instance = plugin,
            Context = pluginContext,
            State = PluginState.Initialized
        };
    }
    
    /// <summary>
    /// 拓扑排序 - 确保依赖插件先加载
    /// </summary>
    private List<PluginDescriptor> TopologicalSort(List<PluginDescriptor> descriptors)
    {
        var sorted = new List<PluginDescriptor>();
        var visited = new HashSet<string>();
        var visiting = new HashSet<string>();
        
        void Visit(PluginDescriptor desc)
        {
            if (visited.Contains(desc.Metadata.Id)) return;
            if (visiting.Contains(desc.Metadata.Id))
                throw new PluginException($"检测到循环依赖: {desc.Metadata.Name}");
            
            visiting.Add(desc.Metadata.Id);
            
            foreach (var depId in desc.Metadata.Dependencies)
            {
                var dep = descriptors.Find(d => d.Metadata.Id == depId);
                if (dep != null) Visit(dep);
            }
            
            visiting.Remove(desc.Metadata.Id);
            visited.Add(desc.Metadata.Id);
            sorted.Add(desc);
        }
        
        foreach (var desc in descriptors) Visit(desc);
        return sorted;
    }
}
```

## 插件通信机制

插件间通信是解耦的关键。采用**事件总线** + **服务定位**的双模式通信架构。

### 事件总线模式（松耦合）

适用于"发布者不知道谁在消费"的场景：

```csharp
public class EventBus
{
    private readonly Dictionary<Type, List<WeakReference<object>>> _handlers = new();
    private readonly object _lock = new();
    
    public IDisposable Subscribe<TEvent>(Action<TEvent> handler) where TEvent : class
    {
        var wrapper = new EventHandlerWrapper<TEvent>(handler, this);
        lock (_lock)
        {
            var type = typeof(TEvent);
            if (!_handlers.ContainsKey(type))
                _handlers[type] = new List<WeakReference<object>>();
            _handlers[type].Add(new WeakReference<object>(wrapper));
        }
        return wrapper; // 返回Disposable用于取消订阅
    }
    
    public void Publish<TEvent>(TEvent @event) where TEvent : class
    {
        List<EventHandlerWrapper<TEvent>> aliveHandlers;
        lock (_lock)
        {
            var type = typeof(TEvent);
            if (!_handlers.TryGetValue(type, out var weakRefs)) return;
            
            // 清理已GC的订阅者
            aliveHandlers = new List<EventHandlerWrapper<TEvent>>();
            var deadIndices = new List<int>();
            
            for (int i = weakRefs.Count - 1; i >= 0; i--)
            {
                if (weakRefs[i].TryGetTarget(out var target))
                {
                    if (target is EventHandlerWrapper<TEvent> wrapper)
                        aliveHandlers.Add(wrapper);
                }
                else
                {
                    weakRefs.RemoveAt(i);
                }
            }
        }
        
        // 在锁外执行回调，避免死锁
        foreach (var handler in aliveHandlers)
        {
            try { handler.Invoke(@event); }
            catch (Exception ex)
            {
                Debug.LogError($"事件处理异常: {ex}");
            }
        }
    }
}

internal class EventHandlerWrapper<TEvent> : IDisposable
{
    private readonly Action<TEvent> _handler;
    private readonly EventBus _bus;
    private bool _disposed;
    
    public EventHandlerWrapper(Action<TEvent> handler, EventBus bus)
    {
        _handler = handler;
        _bus = bus;
    }
    
    public void Invoke(TEvent @event) => _handler?.Invoke(@event);
    
    public void Dispose()
    {
        if (!_disposed)
        {
            _disposed = true;
            // 取消订阅逻辑
        }
    }
}
```

## 插件的动态加载与热插拔

### 程序集隔离加载

使用独立的AssemblyLoadContext实现插件的隔离加载和卸载：

```csharp
public class PluginAssemblyLoader
{
    private readonly Dictionary<string, PluginAssemblyContext> _contexts = new();
    private readonly string _pluginRoot;
    
    public PluginAssemblyLoader(string pluginRoot)
    {
        _pluginRoot = pluginRoot;
    }
    
    /// <summary>
    /// 加载插件程序集到独立上下文
    /// </summary>
    public Assembly LoadPluginAssembly(string pluginId, string assemblyName)
    {
        var context = new PluginAssemblyContext(pluginId);
        var assemblyPath = Path.Combine(_pluginRoot, pluginId, assemblyName);
        var assembly = context.LoadFromAssemblyPath(assemblyPath);
        _contexts[pluginId] = context;
        return assembly;
    }
    
    /// <summary>
    /// 卸载插件程序集
    /// </summary>
    public bool UnloadPluginAssembly(string pluginId)
    {
        if (_contexts.TryGetValue(pluginId, out var context))
        {
            context.Unload();
            _contexts.Remove(pluginId);
            // 强制GC回收卸载的程序集
            GC.Collect();
            GC.WaitForPendingFinalizers();
            return true;
        }
        return false;
    }
}

/// <summary>
/// 插件程序集加载上下文 - 支持卸载
/// </summary>
internal class PluginAssemblyContext : AssemblyLoadContext
{
    private readonly string _pluginId;
    
    public PluginAssemblyContext(string pluginId) : base(isCollectible: true)
    {
        _pluginId = pluginId;
    }
    
    protected override Assembly Load(AssemblyName assemblyName)
    {
        // 共享程序集走默认加载上下文
        var sharedAssemblies = new HashSet<string>
        {
            "mscorlib", "System", "UnityEngine", "CoreRuntime"
        };
        
        if (sharedAssemblies.Contains(assemblyName.Name))
            return Assembly.Load(assemblyName);
        
        return null; // 从插件目录加载
    }
}
```

### 热插拔的挑战与解决方案

| 挑战 | 解决方案 |
|------|---------|
| 卸载时对象引用残留 | 所有跨插件对象引用使用弱引用（WeakReference） |
| 事件订阅未取消 | 插件销毁时自动清理所有订阅 |
| MonoBehaviour残留 | 插件管理的GameObject必须标记为DontDestroyOnLoad并统一清理 |
| 协程未停止 | 使用插件域管理的CoroutineRunner |
| 静态状态 | 禁止插件使用静态字段存储状态 |

```csharp
public class PluginSafeCoroutineRunner : IDisposable
{
    private readonly MonoBehaviour _runner;
    private readonly List<Coroutine> _activeCoroutines = new();
    
    public PluginSafeCoroutineRunner(string pluginId)
    {
        var go = new GameObject($"__CoroutineRunner_{pluginId}__");
        GameObject.DontDestroyOnLoad(go);
        _runner = go.AddComponent<CoroutineRunnerBehaviour>();
        _runner.OnDestroyed += () => StopAll();
    }
    
    public Coroutine StartCoroutine(IEnumerator routine)
    {
        var coroutine = _runner.StartCoroutine(WrapCoroutine(routine));
        _activeCoroutines.Add(coroutine);
        return coroutine;
    }
    
    private IEnumerator WrapCoroutine(IEnumerator routine)
    {
        yield return routine;
        _activeCoroutines.RemoveAll(c => c == null);
    }
    
    public void StopAll()
    {
        foreach (var c in _activeCoroutines)
        {
            if (c != null) _runner.StopCoroutine(c);
        }
        _activeCoroutines.Clear();
    }
    
    public void Dispose()
    {
        StopAll();
        if (_runner != null)
            GameObject.Destroy(_runner.gameObject);
    }
}
```

## 插件版本管理与兼容性

### 语义化版本控制

采用SemVer 2.0规范管理插件版本：

```csharp
public struct PluginVersion : IComparable<PluginVersion>
{
    public int Major { get; }
    public int Minor { get; }
    public int Patch { get; }
    public string PreRelease { get; }
    
    public PluginVersion(int major, int minor, int patch, string preRelease = null)
    {
        Major = major;
        Minor = minor;
        Patch = patch;
        PreRelease = preRelease;
    }
    
    /// <summary>
    /// 检查版本兼容性
    /// 主版本号不同 → 不兼容（Breaking Change）
    /// 次版本号不同 → 向后兼容（新增功能）
    /// 修订号不同 → 完全兼容（Bug修复）
    /// </summary>
    public bool IsCompatibleWith(PluginVersion required)
    {
        if (Major != required.Major) return false;
        if (Minor < required.Minor) return false;
        return true;
    }
    
    public int CompareTo(PluginVersion other)
    {
        if (Major != other.Major) return Major.CompareTo(other.Major);
        if (Minor != other.Minor) return Minor.CompareTo(other.Minor);
        return Patch.CompareTo(other.Patch);
    }
    
    public static PluginVersion Parse(string version)
    {
        var parts = version.Split('-');
        var numbers = parts[0].Split('.');
        return new PluginVersion(
            int.Parse(numbers[0]),
            int.Parse(numbers[1]),
            int.Parse(numbers[2]),
            parts.Length > 1 ? parts[1] : null
        );
    }
    
    public override string ToString() =>
        PreRelease != null ? $"{Major}.{Minor}.{Patch}-{PreRelease}" : $"{Major}.{Minor}.{Patch}";
}
```

### 版本约束解析

```csharp
/// <summary>
/// 版本约束表达式解析器
/// 支持：>=1.0.0, ^1.2.0, ~1.2.3, 1.x, *
/// </summary>
public class VersionConstraint
{
    private enum Op { Any, Exact, GreaterOrEqual, Compatible, Approximately }
    
    private readonly Op _operator;
    private readonly PluginVersion _version;
    
    public bool IsSatisfiedBy(PluginVersion version)
    {
        return _operator switch
        {
            Op.Any => true,
            Op.Exact => version == _version,
            Op.GreaterOrEqual => version >= _version,
            Op.Compatible => version.Major == _version.Major && version >= _version,
            Op.Approximately => version.Major == _version.Major 
                                && version.Minor == _version.Minor 
                                && version >= _version,
            _ => false
        };
    }
    
    public static VersionConstraint Parse(string constraint)
    {
        constraint = constraint.Trim();
        
        if (constraint == "*" || constraint == "x")
            return new VersionConstraint { _operator = Op.Any };
        
        if (constraint.StartsWith(">="))
            return new VersionConstraint 
            { 
                _operator = Op.GreaterOrEqual, 
                _version = PluginVersion.Parse(constraint[2..].Trim()) 
            };
        
        if (constraint.StartsWith("^"))
            return new VersionConstraint 
            { 
                _operator = Op.Compatible, 
                _version = PluginVersion.Parse(constraint[1..].Trim()) 
            };
        
        if (constraint.StartsWith("~"))
            return new VersionConstraint 
            { 
                _operator = Op.Approximately, 
                _version = PluginVersion.Parse(constraint[1..].Trim()) 
            };
        
        return new VersionConstraint 
        { 
            _operator = Op.Exact, 
            _version = PluginVersion.Parse(constraint) 
        };
    }
}
```

```csharp
[Serializable]
public class PluginConfig
{
    public bool Enabled = true;
    public int LoadPriority = 100;

public class PluginConfigManager
{
    private readonly string _configRoot;
    private readonly Dictionary<string, PluginConfig> _configCache = new();
    private readonly FileSystemWatcher _watcher;
    
    public PluginConfigManager(string configRoot)
    {
        _configRoot = configRoot;
        _watcher = new FileSystemWatcher(configRoot, "*.json");
        _watcher.Changed += OnConfigChanged;
        _watcher.EnableRaisingEvents = true;
    }
    
    public T GetConfig<T>(string pluginId) where T : class, new()
    {
        var configPath = GetConfigPath(pluginId);
        if (!File.Exists(configPath))
            return new T();
        
        var json = File.ReadAllText(configPath);
        return JsonUtility.FromJson<T>(json);
    }
    
    public void SaveConfig<T>(string pluginId, T config) where T : class
    {
        var json = JsonUtility.ToJson(config, prettyPrint: true);
        File.WriteAllText(GetConfigPath(pluginId), json);
    }
    
    private void OnConfigChanged(object sender, FileSystemEventArgs e)
    {
        var pluginId = Path.GetFileNameWithoutExtension(e.Name);
        // 触发配置热重载事件
        PluginEventBus.Publish(new ConfigReloadedEvent(pluginId));
    }
    
    private string GetConfigPath(string pluginId) =>
        Path.Combine(_configRoot, $"{pluginId}.config.json");
}
```

## 插件依赖注入容器

```csharp
public class PluginServiceContainer
{
    private readonly Dictionary<Type, ServiceDescriptor> _services = new();
    private readonly Dictionary<Type, object> _singletons = new();
    
    public void Register<TService>(TService instance, ServiceLifetime lifetime = ServiceLifetime.Singleton)
        where TService : class
    {
        _services[typeof(TService)] = new ServiceDescriptor
        {
            ServiceType = typeof(TService),
            ImplementationType = instance.GetType(),
            Instance = instance,
            Lifetime = lifetime
        };
        
        if (lifetime == ServiceLifetime.Singleton)
            _singletons[typeof(TService)] = instance;
    }
    
    public void Register<TService, TImplementation>(ServiceLifetime lifetime = ServiceLifetime.Transient)
        where TService : class
        where TImplementation : class, TService
    {
        _services[typeof(TService)] = new ServiceDescriptor
        {
            ServiceType = typeof(TService),
            ImplementationType = typeof(TImplementation),
            Lifetime = lifetime
        };
    }
    
    public TService Resolve<TService>() where TService : class
    {
        return (TService)Resolve(typeof(TService));
    }
    
    private object Resolve(Type serviceType)
    {
        if (!_services.TryGetValue(serviceType, out var descriptor))
            throw new PluginException($"服务 {serviceType.Name} 未注册");
        
        if (descriptor.Lifetime == ServiceLifetime.Singleton)
        {
            if (_singletons.TryGetValue(serviceType, out var singleton))
                return singleton;
            
            var instance = CreateInstance(descriptor.ImplementationType);
            _singletons[serviceType] = instance;
            return instance;
        }
        
        return CreateInstance(descriptor.ImplementationType);
    }
    
    private object CreateInstance(Type type)
    {
        var constructors = type.GetConstructors();
        if (constructors.Length == 0)
            return Activator.CreateInstance(type);
        
        // 构造函数注入
        var constructor = constructors[0];
        var parameters = constructor.GetParameters();
        var args = new object[parameters.Length];
        
        for (int i = 0; i < parameters.Length; i++)
        {
            args[i] = Resolve(parameters[i].ParameterType);
        }
        
        return constructor.Invoke(args);
    }
}

public enum ServiceLifetime
{
    Singleton,  // 全局唯一实例
    Transient,  // 每次获取创建新实例
    Scoped      // 插件域内唯一
}

internal class ServiceDescriptor
{
    public Type ServiceType;
    public Type ImplementationType;
    public object Instance;
    public ServiceLifetime Lifetime;
}
```

## 插件资源隔离

每个插件的资源（Prefab、Texture、Shader等）应独立管理，避免命名冲突：

```csharp
public class PluginResourceManager : IDisposable
{
    private readonly string _pluginId;
    private readonly AssetBundle _assetBundle;
    private readonly Dictionary<string, Object> _cache = new();
    
    public PluginResourceManager(string pluginId, string bundlePath)
    {
        _pluginId = pluginId;
        
        // 每个插件独立AssetBundle
        if (File.Exists(bundlePath))
            _assetBundle = AssetBundle.LoadFromFile(bundlePath);
    }
    
    /// <summary>
    /// 加载插件资源 - 自动添加插件ID前缀避免冲突
    /// </summary>
    public T Load<T>(string resourceName) where T : Object
    {
        var key = $"{_pluginId}:{resourceName}";
        
        if (_cache.TryGetValue(key, out var cached))
            return cached as T;
        
        // 优先从AssetBundle加载
        T asset = null;
        if (_assetBundle != null)
            asset = _assetBundle.LoadAsset<T>(resourceName);
        
        // 回退到Resources
        if (asset == null)
            asset = Resources.Load<T>($"Plugins/{_pluginId}/{resourceName}");
        
        if (asset != null)
            _cache[key] = asset;
        
        return asset;
    }
    
    /// <summary>
    /// 实例化插件Prefab - 自动注入插件标识
    /// </summary>
    public GameObject Instantiate(string prefabName, Transform parent = null)
    {
        var prefab = Load<GameObject>(prefabName);
        if (prefab == null) return null;
        
        var instance = GameObject.Instantiate(prefab, parent);
        instance.name = $"[{_pluginId}]{instance.name}";
        
        // 标记插件归属
        var marker = instance.GetComponent<PluginGameObjectMarker>();
        if (marker == null)
            marker = instance.AddComponent<PluginGameObjectMarker>();
        marker.PluginId = _pluginId;
        
        return instance;
    }
    
    public void Dispose()
    {
        if (_assetBundle != null)
            _assetBundle.Unload(true);
        _cache.Clear();
    }
}

/// <summary>

/// 用于插件卸载时自动清理
/// </summary>
public class PluginGameObjectMarker : MonoBehaviour

    public string PluginId;
```

```csharp
public class PluginMemoryTracker
{
    private readonly Dictionary<string, long> _pluginMemoryUsage = new();
    private readonly Dictionary<string, List<WeakReference>> _trackedObjects = new();
    
    public void TrackObject(string pluginId, object obj)
    {
        if (!_trackedObjects.ContainsKey(pluginId))
            _trackedObjects[pluginId] = new List<WeakReference>();
        _trackedObjects[pluginId].Add(new WeakReference(obj));
    }
    
    /// <summary>
    /// 检查插件是否有内存泄漏
    /// </summary>
    public PluginMemoryReport AnalyzeMemory(string pluginId)
    {
        if (!_trackedObjects.TryGetValue(pluginId, out var refs))
            return new PluginMemoryReport { PluginId = pluginId, LeakedObjects = 0 };
        
        int alive = 0;
        foreach (var wr in refs)
        {
            if (wr.IsAlive) alive++;
        }
        
        return new PluginMemoryReport
        {
            PluginId = pluginId,
            TotalTracked = refs.Count,
            LeakedObjects = alive
        };
    }
}
```

## 最佳实践总结

### 架构设计原则

1. **接口隔离**：每个插件只依赖抽象接口，不依赖具体实现
2. **单向依赖**：依赖方向从业务层指向基础设施层，杜绝循环依赖
3. **契约优先**：先定义插件间的通信契约，再实现具体逻辑
4. **版本兼容**：严格遵守SemVer规范，Breaking Change必须升主版本号

### 工程实践建议

1. **渐进式迁移**：不要一次性重构为插件架构，从边界清晰的模块开始逐步迁移
2. **自动化测试**：为每个插件的公共接口编写单元测试，CI中自动运行
3. **监控告警**：插件加载时间、内存占用、异常次数等指标上报监控系统
4. **降级策略**：核心插件加载失败时提供降级方案，保证游戏可运行
5. **文档即契约**：插件接口文档与代码同步维护，使用工具自动生成API文档

### 常见反模式

| 反模式 | 问题 | 正确做法 |
|--------|------|---------|
| 插件间直接引用 | 破坏解耦，升级困难 | 通过服务接口或事件通信 |
| 共享静态状态 | 线程安全、卸载泄漏 | 使用DI容器管理状态 |
| 过度拆分 | 管理成本超过收益 | 按业务边界合理粒度拆分 |
| 忽略卸载 | 内存泄漏累积 | 每个插件必须实现完整的销毁逻辑 |
| 配置硬编码 | 插件缺乏灵活性 | 使用外部配置文件+热重载 |

## 结语

插件化架构不是银弹，它带来了模块化、可扩展性的同时，也引入了额外的复杂度和性能开销。关键在于根据项目规模和团队情况，在合适的时机引入合适的抽象层次。对于中小型项目，轻量级的模块化方案可能比完整的插件系统更合适；而对于大型项目和需要支持第三方扩展的商业引擎，完善的插件化架构则是必不可少的基石。

从工程实践来看，成功的插件化架构往往遵循"先有模块，后有插件"的演进路径——先通过接口和依赖注入理清模块边界，再逐步引入动态加载和热插拔能力。这种渐进式的方式既能控制风险，又能让团队在实践中积累对架构的深刻理解。
