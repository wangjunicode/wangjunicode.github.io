# 游戏自适应音乐系统——程序化动态音乐状态机完全指南

游戏音乐面临着电影音乐不曾遇到的根本性挑战：**交互性**。电影的情绪曲线是确定的，而游戏玩家的行为完全不可预测——他们可能在激烈战斗中突然停手发呆，也可能在安静探索时猝然触发Boss战。

**自适应音乐（Adaptive Music）** 正是为解决这一矛盾而生：音乐系统实时感知游戏状态，动态调整音乐的情绪、激烈程度与编排，让玩家无论何时都身处"完全正确"的音乐氛围中。《The Last of Us》《荒野大镖客2》《塞尔达：旷野之息》都是这一技术的旗舰案例。

本文将从零构建一套完整的自适应音乐系统，涵盖架构设计、算法实现和工程落地。

## 1. 自适应音乐技术全景

### 1.1 三种核心技术路径

```
自适应音乐技术路径
│
├── 水平切换（Horizontal Re-sequencing）
│   原理：多个完整音乐片段，根据状态切换播放哪一段
│   优点：制作简单，效果可预期
│   缺点：切换边界感明显，片段较多时存储大
│   适用：RPG 场景音乐切换（安全区→危险区）
│
├── 垂直分层（Vertical Layering）
│   原理：同一段音乐拆分为多个音轨层，根据状态叠加/静音各层
│   优点：过渡自然，存储节约，情绪细腻
│   缺点：制作要求高（各层需要独立录音且和谐叠加）
│   适用：战斗激烈程度渐进（探索→警觉→战斗→高潮）
│
└── 程序化生成（Procedural Generation）
    原理：实时合成音乐素材，参数化控制情绪
    优点：完全连续，无重复感
    缺点：技术复杂，音乐质量难以控制
    适用：开放世界探索、节奏类游戏
```

## 2. 核心架构设计

### 2.1 音乐状态机

```csharp
using UnityEngine;
using System;
using System.Collections;
using System.Collections.Generic;

/// <summary>
/// 音乐情绪状态枚举
/// </summary>
public enum MusicMood
{
    Silence = 0,
    Ambient,        // 环境音（低强度背景）
    Explore,        // 探索（轻松、好奇）
    Tension,        // 紧张（警觉、发现敌人）
    Combat_Light,   // 轻度战斗
    Combat_Heavy,   // 激烈战斗
    Combat_Boss,    // Boss战
    Victory,        // 胜利
    Defeat,         // 失败
    Cutscene,       // 过场剧情
    Safe_Zone       // 安全区/城镇
}

/// <summary>
/// 音乐状态转换配置
/// </summary>
[System.Serializable]
public class MusicTransition
{
    public MusicMood  from;
    public MusicMood  to;
    public float      crossfadeDuration = 1.5f;   // 淡入淡出时长
    public bool       waitForBeat       = true;    // 是否等待节拍边界
    public float      delaySeconds      = 0f;      // 延迟触发（如战斗结束后延迟3s才切换）
}

/// <summary>
/// 音乐状态机核心
/// </summary>
public class MusicStateMachine : MonoBehaviour
{
    public static MusicStateMachine Instance { get; private set; }

    [Header("转换配置")]
    public List<MusicTransition> transitions;

    // 当前状态
    public MusicMood CurrentMood  { get; private set; } = MusicMood.Silence;
    public MusicMood PreviousMood { get; private set; } = MusicMood.Silence;

    // 事件
    public event Action<MusicMood, MusicMood> OnMoodChanged;

    // 挂起的状态请求（等待延迟或节拍边界）
    private MusicMood? _pendingMood;
    private Coroutine  _pendingCoroutine;

    void Awake()
    {
        if (Instance != null) { Destroy(gameObject); return; }
        Instance = this;
        DontDestroyOnLoad(gameObject);
    }

    /// <summary>
    /// 请求切换音乐状态（会根据转换配置决定是否等待节拍等）
    /// </summary>
    public void RequestMood(MusicMood newMood, bool immediate = false)
    {
        if (newMood == CurrentMood && _pendingMood == null) return;

        // 取消上一个挂起请求
        if (_pendingCoroutine != null)
        {
            StopCoroutine(_pendingCoroutine);
            _pendingCoroutine = null;
        }

        MusicTransition trans = FindTransition(CurrentMood, newMood);
        float delay = (trans != null) ? trans.delaySeconds : 0f;

        if (immediate || delay <= 0f)
        {
            ExecuteMoodChange(newMood, trans);
        }
        else
        {
            _pendingMood = newMood;
            _pendingCoroutine = StartCoroutine(DelayedMoodChange(newMood, trans, delay));
        }
    }

    private IEnumerator DelayedMoodChange(MusicMood newMood, MusicTransition trans, float delay)
    {
        yield return new WaitForSeconds(delay);
        ExecuteMoodChange(newMood, trans);
        _pendingMood = null;
    }

    private void ExecuteMoodChange(MusicMood newMood, MusicTransition trans)
    {
        PreviousMood = CurrentMood;
        CurrentMood  = newMood;

        float crossfade  = trans?.crossfadeDuration ?? 1.5f;
        bool  waitBeat   = trans?.waitForBeat ?? true;

        Debug.Log($"[MusicSM] 状态切换: {PreviousMood} → {CurrentMood}");
        OnMoodChanged?.Invoke(PreviousMood, CurrentMood);

        // 通知 MusicPlayer 执行实际切换
        MusicLayerPlayer.Instance?.TransitionToMood(CurrentMood, crossfade, waitBeat);
    }

    private MusicTransition FindTransition(MusicMood from, MusicMood to)
    {
        foreach (var t in transitions)
            if (t.from == from && t.to == to)
                return t;
        return null;
    }
}
```

## 3. 垂直分层混音播放器

```csharp
using UnityEngine;
using System.Collections;
using System.Collections.Generic;

/// <summary>
/// 单个音乐层配置
/// </summary>
[System.Serializable]
public class MusicLayer
{
    public string     name;
    public AudioClip  clip;
    [Range(0, 1)]
    public float      baseVolume   = 1f;      // 该层的基础音量
    public MusicMood  activeFromMood;          // 从哪个情绪强度开始启用此层
    [HideInInspector]
    public AudioSource source;
}

/// <summary>
/// 音乐状态包（一组分层音轨 + 元数据）
/// </summary>
[CreateAssetMenu(menuName = "Audio/Music Cue")]
public class MusicCue : ScriptableObject
{
    public MusicMood      mood;
    public float          bpm          = 120f;     // 用于节拍对齐
    public int            beatsPerBar  = 4;
    public List<MusicLayer> layers;
    [Range(0, 1)]
    public float          masterVolume = 1f;
    [Tooltip("循环时从这个时间点开始（秒），-1 = 从头循环")]
    public float          loopStart    = -1f;
}

/// <summary>
/// 垂直分层音乐播放器
/// </summary>
public class MusicLayerPlayer : MonoBehaviour
{
    public static MusicLayerPlayer Instance { get; private set; }

    [Header("Cue 配置")]
    public List<MusicCue> musicCues;

    [Header("播放设置")]
    public float defaultCrossfade = 1.5f;

    // 当前/下一个 Cue
    private MusicCue _currentCue;
    private MusicCue _nextCue;

    // Beat 时钟
    private BeatClock _beatClock;

    // AudioSource 池（每个 Cue 的每个 Layer 都有独立 AudioSource）
    private Dictionary<MusicCue, List<AudioSource>> _sourcePools
        = new Dictionary<MusicCue, List<AudioSource>>();

    // 当前各层目标音量（用于平滑过渡）
    private Dictionary<AudioSource, Coroutine> _fadeCoroutines
        = new Dictionary<AudioSource, Coroutine>();

    void Awake()
    {
        if (Instance != null) { Destroy(gameObject); return; }
        Instance = this;
        DontDestroyOnLoad(gameObject);

        _beatClock = GetComponent<BeatClock>() ?? gameObject.AddComponent<BeatClock>();
        PrepareAllCues();
    }

    /// <summary>
    /// 预加载所有 Cue 的 AudioSource
    /// </summary>
    private void PrepareAllCues()
    {
        foreach (var cue in musicCues)
        {
            var sources = new List<AudioSource>();
            foreach (var layer in cue.layers)
            {
                var go  = new GameObject($"[Layer] {cue.mood}/{layer.name}");
                go.transform.SetParent(transform);

                var src = go.AddComponent<AudioSource>();
                src.clip        = layer.clip;
                src.loop        = true;
                src.volume      = 0f;          // 初始静音
                src.playOnAwake = false;
                src.spatialBlend= 0f;          // 2D 音乐

                layer.source = src;
                sources.Add(src);
            }
            _sourcePools[cue] = sources;
        }
    }

    /// <summary>
    /// 切换到指定情绪的音乐
    /// </summary>
    public void TransitionToMood(MusicMood mood, float crossfade, bool waitForBeat)
    {
        MusicCue targetCue = FindCue(mood);
        if (targetCue == null)
        {
            Debug.LogWarning($"[MusicPlayer] 找不到 Cue: {mood}，静音");
            FadeOutCurrentCue(crossfade);
            return;
        }

        if (waitForBeat && _currentCue != null)
        {
            // 等到下一个小节开始时切换
            _beatClock.OnNextBar(() =>
            {
                PerformTransition(targetCue, crossfade);
            });
        }
        else
        {
            PerformTransition(targetCue, crossfade);
        }
    }

    private void PerformTransition(MusicCue targetCue, float crossfade)
    {
        if (_currentCue == targetCue) return;

        // 1. 淡出旧 Cue
        if (_currentCue != null)
            FadeOutCue(_currentCue, crossfade);

        // 2. 启动新 Cue（如果尚未播放则先同步到正确时间点）
        _currentCue = targetCue;
        SyncAndFadeInCue(targetCue, crossfade);
    }

    private void SyncAndFadeInCue(MusicCue cue, float fadeDuration)
    {
        // 所有层同步播放（保证对齐）
        double dspTime = AudioSettings.dspTime + 0.05;   // 小延迟确保精确同步

        foreach (var layer in cue.layers)
        {
            if (!layer.source.isPlaying)
            {
                // 首次播放：从循环起点开始
                if (cue.loopStart >= 0)
                    layer.source.time = cue.loopStart;
                layer.source.PlayScheduled(dspTime);
            }
            // 淡入到目标音量（根据当前情绪决定该层是否激活）
            float targetVol = IsLayerActiveForCurrentMood(layer, cue) ? layer.baseVolume * cue.masterVolume : 0f;
            FadeTo(layer.source, targetVol, fadeDuration);
        }
    }

    private void FadeOutCue(MusicCue cue, float fadeDuration)
    {
        foreach (var layer in cue.layers)
        {
            FadeTo(layer.source, 0f, fadeDuration, () =>
            {
                if (cue != _currentCue)   // 确保是老 Cue
                    layer.source.Stop();
            });
        }
    }

    private void FadeOutCurrentCue(float fadeDuration)
    {
        if (_currentCue == null) return;
        FadeOutCue(_currentCue, fadeDuration);
        _currentCue = null;
    }

    /// <summary>
    /// 判断某一层在当前情绪强度下是否应该激活
    /// </summary>
    private bool IsLayerActiveForCurrentMood(MusicLayer layer, MusicCue cue)
    {
        return (int)cue.mood >= (int)layer.activeFromMood;
    }

    /// <summary>
    /// 动态调整情绪强度下的各层音量（用于战斗激烈度渐变等场景）
    /// </summary>
    public void SetIntensity(float intensity)  // intensity [0, 1]
    {
        if (_currentCue == null) return;
        int   layerCount = _currentCue.layers.Count;
        float perLayer   = 1f / Mathf.Max(1, layerCount - 1);

        for (int i = 0; i < layerCount; i++)
        {
            var layer       = _currentCue.layers[i];
            float threshold = i * perLayer;
            float vol       = Mathf.Clamp01((intensity - threshold) / perLayer)
                              * layer.baseVolume * _currentCue.masterVolume;
            FadeTo(layer.source, vol, 0.3f);
        }
    }

    private void FadeTo(AudioSource src, float targetVol, float duration, Action onComplete = null)
    {
        if (_fadeCoroutines.TryGetValue(src, out var existing) && existing != null)
            StopCoroutine(existing);
        _fadeCoroutines[src] = StartCoroutine(FadeCoroutine(src, targetVol, duration, onComplete));
    }

    private IEnumerator FadeCoroutine(AudioSource src, float target, float duration, Action onComplete)
    {
        float start = src.volume;
        float elapsed = 0f;
        while (elapsed < duration)
        {
            elapsed    += Time.unscaledDeltaTime;
            src.volume  = Mathf.Lerp(start, target, elapsed / duration);
            yield return null;
        }
        src.volume = target;
        onComplete?.Invoke();
    }

    private MusicCue FindCue(MusicMood mood)
    {
        foreach (var cue in musicCues)
            if (cue.mood == mood)
                return cue;
        return null;
    }
}
```

## 4. 节拍时钟（Beat Clock）

节拍对齐是自适应音乐的精髓——在节拍边界切换音乐，完全感知不到拼接感。

```csharp
using UnityEngine;
using System;
using System.Collections.Generic;

/// <summary>
/// BPM 驱动的节拍时钟，提供精确的 Beat/Bar 时间节点回调
/// </summary>
public class BeatClock : MonoBehaviour
{
    [Header("BPM 设置")]
    public float bpm         = 120f;
    public int   beatsPerBar = 4;

    // 当前节拍计数（从0开始）
    public int  CurrentBeat { get; private set; }
    public int  CurrentBar  { get; private set; }

    // 在下一个 Beat/Bar 触发的回调
    private readonly Queue<Action> _nextBeatCallbacks = new();
    private readonly Queue<Action> _nextBarCallbacks  = new();

    // 事件
    public event Action<int> OnBeat;   // 参数：Beat index
    public event Action<int> OnBar;    // 参数：Bar index

    private float _beatDuration;       // 单个 Beat 时长（秒）
    private float _barDuration;        // 单个 Bar 时长（秒）
    private float _timer;              // 当前 Beat 内累计时间

    void Start()
    {
        SetBPM(bpm);
    }

    public void SetBPM(float newBpm)
    {
        bpm           = newBpm;
        _beatDuration = 60f / bpm;
        _barDuration  = _beatDuration * beatsPerBar;
    }

    void Update()
    {
        _timer += Time.unscaledDeltaTime;

        if (_timer >= _beatDuration)
        {
            _timer -= _beatDuration;
            CurrentBeat++;

            // 触发 Beat 事件
            OnBeat?.Invoke(CurrentBeat);
            FlushCallbacks(_nextBeatCallbacks);

            // 检查是否到了新 Bar
            if (CurrentBeat % beatsPerBar == 0)
            {
                CurrentBar++;
                OnBar?.Invoke(CurrentBar);
                FlushCallbacks(_nextBarCallbacks);
            }
        }
    }

    /// <summary>
    /// 在下一个 Beat 时执行回调
    /// </summary>
    public void OnNextBeat(Action callback)
        => _nextBeatCallbacks.Enqueue(callback);

    /// <summary>
    /// 在下一个 Bar 开始时执行回调
    /// </summary>
    public void OnNextBar(Action callback)
        => _nextBarCallbacks.Enqueue(callback);

    /// <summary>
    /// 获取到下一个 Beat 的剩余时间
    /// </summary>
    public float TimeToNextBeat => _beatDuration - _timer;

    /// <summary>
    /// 获取到下一个 Bar 的剩余时间
    /// </summary>
    public float TimeToNextBar
    {
        get
        {
            int beatsInCurrentBar  = CurrentBeat % beatsPerBar;
            int beatsUntilNextBar  = beatsPerBar - beatsInCurrentBar;
            return (beatsUntilNextBar - 1) * _beatDuration + TimeToNextBeat;
        }
    }

    private void FlushCallbacks(Queue<Action> queue)
    {
        while (queue.Count > 0)
            queue.Dequeue()?.Invoke();
    }
}
```

## 5. 游戏情境感知与状态驱动

### 5.1 战斗激烈度感知器

```csharp
using UnityEngine;

/// <summary>
/// 战斗感知器：监控战斗相关参数，驱动音乐情绪切换
/// </summary>
public class CombatMusicDriver : MonoBehaviour
{
    [Header("感知配置")]
    [Tooltip("检测范围内有敌人时切换到紧张状态")]
    public float awarenessRadius   = 20f;
    [Tooltip("脱战后多少秒恢复到探索音乐")]
    public float combatExitDelay   = 5f;
    [Tooltip("Boss触发距离")]
    public float bossDetectRadius  = 50f;

    [Header("标签配置")]
    public string enemyTag = "Enemy";
    public string bossTag  = "Boss";

    // 当前战斗状态
    private enum CombatState { Safe, Aware, Combat, Boss }
    private CombatState _combatState = CombatState.Safe;
    private float       _lastCombatTime;

    // 激烈程度 [0,1]：根据视野内敌人数量 × 玩家血量等综合计算
    private float _intensity;

    void Update()
    {
        UpdateCombatState();
        UpdateMusicIntensity();
    }

    private void UpdateCombatState()
    {
        // 检测 Boss
        Collider[] bosses = Physics.OverlapSphere(transform.position, bossDetectRadius,
            LayerMask.GetMask("Enemy"));
        bool bossNearby = false;
        foreach (var col in bosses)
            if (col.CompareTag(bossTag)) { bossNearby = true; break; }

        if (bossNearby)
        {
            SetCombatState(CombatState.Boss);
            return;
        }

        // 检测普通敌人
        Collider[] enemies = Physics.OverlapSphere(transform.position, awarenessRadius,
            LayerMask.GetMask("Enemy"));
        int enemyCount = 0;
        foreach (var col in enemies)
            if (col.CompareTag(enemyTag)) enemyCount++;

        if (enemyCount > 0)
        {
            _lastCombatTime = Time.time;
            SetCombatState(enemyCount >= 3 ? CombatState.Combat : CombatState.Aware);
        }
        else if (_combatState != CombatState.Safe)
        {
            // 脱战后延迟恢复
            if (Time.time - _lastCombatTime > combatExitDelay)
                SetCombatState(CombatState.Safe);
        }
    }

    private void UpdateMusicIntensity()
    {
        if (MusicLayerPlayer.Instance == null) return;

        // 根据视野内敌人数量动态计算激烈程度
        Collider[] enemies = Physics.OverlapSphere(transform.position, awarenessRadius,
            LayerMask.GetMask("Enemy"));
        float targetIntensity = Mathf.Clamp01(enemies.Length / 5f);
        _intensity = Mathf.Lerp(_intensity, targetIntensity, Time.deltaTime * 2f);

        MusicLayerPlayer.Instance.SetIntensity(_intensity);
    }

    private void SetCombatState(CombatState newState)
    {
        if (newState == _combatState) return;
        _combatState = newState;

        MusicMood targetMood = newState switch
        {
            CombatState.Safe   => MusicMood.Explore,
            CombatState.Aware  => MusicMood.Tension,
            CombatState.Combat => MusicMood.Combat_Heavy,
            CombatState.Boss   => MusicMood.Combat_Boss,
            _                  => MusicMood.Explore
        };

        MusicStateMachine.Instance?.RequestMood(targetMood);
    }
}
```

### 5.2 场景区域音乐触发器

```csharp
using UnityEngine;

/// <summary>
/// 场景区域触发器：进入/退出区域时切换音乐情绪
/// </summary>
[RequireComponent(typeof(Collider))]
public class MusicZoneTrigger : MonoBehaviour
{
    [Header("音乐配置")]
    public MusicMood enterMood;          // 进入时切换到的情绪
    public MusicMood exitMood;           // 退出时切换回的情绪
    public bool      restorePrevious;    // true = 退出时恢复进入前的情绪

    [Header("过渡配置")]
    public float     crossfadeDuration = 2f;
    public bool      waitForBeat       = true;

    private MusicMood _previousMood;

    void Start()
    {
        GetComponent<Collider>().isTrigger = true;
    }

    void OnTriggerEnter(Collider other)
    {
        if (!other.CompareTag("Player")) return;
        _previousMood = MusicStateMachine.Instance?.CurrentMood ?? MusicMood.Explore;
        MusicStateMachine.Instance?.RequestMood(enterMood);
    }

    void OnTriggerExit(Collider other)
    {
        if (!other.CompareTag("Player")) return;
        MusicMood mood = restorePrevious ? _previousMood : exitMood;
        MusicStateMachine.Instance?.RequestMood(mood);
    }
}
```

## 6. FMOD 集成方案

对于需要更专业音乐系统的项目，FMOD Studio 提供原生的 Adaptive Music 支持：

```csharp
using UnityEngine;
using FMODUnity;
using FMOD.Studio;

/// <summary>
/// FMOD 自适应音乐控制器
/// 利用 FMOD Studio 的 Parameter 驱动 Music System
/// </summary>
public class FMODAdaptiveMusic : MonoBehaviour
{
    [Header("FMOD Event")]
    [EventRef]
    public string musicEventPath = "event:/Music/MainTheme";

    // FMOD 参数名（需与 FMOD Studio 中定义一致）
    private const string PARAM_INTENSITY = "Intensity";   // 战斗激烈程度 [0, 1]
    private const string PARAM_MOOD      = "Mood";        // 情绪索引
    private const string PARAM_AREA      = "Area";        // 区域索引

    private EventInstance _musicInstance;

    void Start()
    {
        // 创建并开始播放 FMOD 音乐事件
        _musicInstance = RuntimeManager.CreateInstance(musicEventPath);
        _musicInstance.start();

        // 监听状态机切换
        MusicStateMachine.Instance.OnMoodChanged += OnMoodChanged;
    }

    void OnDestroy()
    {
        _musicInstance.stop(FMOD.Studio.STOP_MODE.ALLOWFADEOUT);
        _musicInstance.release();

        if (MusicStateMachine.Instance != null)
            MusicStateMachine.Instance.OnMoodChanged -= OnMoodChanged;
    }

    private void OnMoodChanged(MusicMood from, MusicMood to)
    {
        // 将 MusicMood 映射到 FMOD 参数值
        float moodValue = (float)to;
        _musicInstance.setParameterByName(PARAM_MOOD, moodValue);
        Debug.Log($"[FMOD] 设置 Mood 参数: {to} ({moodValue})");
    }

    /// <summary>
    /// 设置战斗激烈程度（由 CombatMusicDriver 调用）
    /// </summary>
    public void SetIntensity(float intensity)
    {
        _musicInstance.setParameterByName(PARAM_INTENSITY, intensity);
    }

    /// <summary>
    /// 设置当前区域（影响乐器编排风格）
    /// </summary>
    public void SetArea(int areaIndex)
    {
        _musicInstance.setParameterByName(PARAM_AREA, areaIndex);
    }

    /// <summary>
    /// 获取当前播放时间（毫秒），用于同步
    /// </summary>
    public int GetCurrentTimelinePosition()
    {
        _musicInstance.getTimelinePosition(out int position);
        return position;
    }
}
```

## 8. 最佳实践总结

### 8.1 音乐制作流程建议

```
1. 确定情绪状态数量（通常 5~8 个）
2. 为每个情绪状态录制独立的循环片段（或分层音轨）
3. 所有片段必须：
   - 相同 BPM
   - 相同调性（或近关系调）
   - Loop 点精确到小节边界
4. 分层音轨各层要求：
   - 单独录制，可独立静音
   - 叠加时无频率冲突
   - 各层从简单到复杂（打击乐→弦乐→铜管→人声）
```

### 8.2 性能优化

```csharp
// 使用 AudioMixer 进行 CPU 效率更高的音量控制
// 而非直接操作 AudioSource.volume（每帧修改会触发 GC）
public class AudioMixerFader : MonoBehaviour
{
    public UnityEngine.Audio.AudioMixer mixer;

    // AudioMixer 暴露参数：比直接修改 AudioSource 效率高
    public void SetLayerVolume(string exposedParam, float linearVolume)
    {
        // 转换为分贝
        float db = linearVolume > 0.0001f
            ? Mathf.Log10(linearVolume) * 20f
            : -80f;
        mixer.SetFloat(exposedParam, db);
    }
}
```

### 8.3 完整技术选型指南

| 项目规模 | 推荐方案 | 原因 |
|----------|----------|------|
| 独立小游戏 | Unity 原生 AudioSource + 垂直分层 | 无额外授权费，已够用 |
| 中型项目 | Unity AudioMixer + 节拍时钟 + 状态机 | 灵活可控，工具链完整 |
| 大型 AA/AAA | FMOD Studio 集成 | 专业音频设计工具，设计师友好 |
| 开放世界 | Wwise 集成 | 最强大的情境感知与音乐编排系统 |

**工程核心经验：**

1. **节拍对齐是自适应音乐的灵魂** —— 在音乐无感知点（小节边界）切换，效果远胜即时切换，玩家完全感知不到音乐的拼接痕迹。
2. **战斗退出延迟很关键** —— 战斗音乐不能在杀死最后一个敌人时立刻停止，需要 3~5 秒的"脱战延迟"，避免音乐频繁切换。
3. **音乐状态机要与游戏逻辑解耦** —— 通过事件/观察者模式驱动，而非战斗系统直接调用音乐播放接口。
4. **垂直分层音轨的各层需要谨慎设计频段** —— 层叠后高中低频要互补，不能相互掩蔽，这是制作层面最难的挑战。
5. **在 Editor 工具中做好调试面板** —— 音乐设计师和程序需要能实时切换情绪状态，快速验证过渡效果，这比自测更重要。
