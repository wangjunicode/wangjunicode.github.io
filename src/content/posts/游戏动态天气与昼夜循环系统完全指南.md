# 游戏动态天气与昼夜循环系统完全指南：从物理模拟到渲染集成

## 引言

动态天气与昼夜循环是开放世界游戏中提升沉浸感的核心系统之一。《塞尔达传说：旷野之息》的雨天增加攀爬难度、《荒野大镖客2》随时间变化的光影效果，都是这类系统的典范应用。本文将从底层物理模拟到上层渲染集成，完整讲解如何构建一套生产级别的动态天气与昼夜循环系统。

## 系统架构总览

```
WeatherSystem (核心管理器)
├── TimeSystem          // 游戏时间管理、时间缩放
├── CelestialSystem     // 天体运动（太阳/月亮/星空）
├── AtmosphereSystem    // 大气散射与天空盒
├── WeatherStateMachine // 天气状态机（晴/云/雨/雪/雷暴）
├── CloudSystem         // 云层系统（体积云/2D云）
├── PrecipitationSystem // 降水系统（雨/雪/雾）
├── LightingSystem      // 动态光照（环境光/方向光/雾效）
└── WeatherEventBus     // 天气事件总线（供其他系统订阅）
```

## 一、游戏时间系统（TimeSystem）

### 1.1 时间管理器设计

```csharp
using UnityEngine;
using System;

[Serializable]
public struct GameDateTime
{
    public int Day;
    public float Hour;       // 0-24
    public float Minute;     // 0-60
    
    public float TotalHours => Day * 24f + Hour + Minute / 60f;
    
    // 归一化时间 0-1，0=午夜，0.5=正午
    public float NormalizedTime => Hour / 24f;
    
    public bool IsNight => Hour < 6f || Hour >= 20f;
    public bool IsGoldenHour => (Hour >= 5.5f && Hour <= 7f) || 
                                 (Hour >= 18f && Hour <= 19.5f);

    public override string ToString() => 
        $"Day {Day} {(int)Hour:D2}:{(int)Minute:D2}";
}

public class TimeSystem : MonoBehaviour
{
    [Header("时间配置")]
    [SerializeField] private float _realSecondsPerGameHour = 60f; // 1现实分钟=1游戏小时
    [SerializeField] private float _timeScale = 1f;
    [SerializeField] private GameDateTime _startTime = new GameDateTime { Day = 1, Hour = 8 };
    
    [Header("Debug")]
    [SerializeField] private bool _pauseTime = false;
    
    private GameDateTime _currentTime;
    private float _accumulatedSeconds;
    
    public GameDateTime CurrentTime => _currentTime;
    public float NormalizedTime => _currentTime.NormalizedTime;
    public float TimeScale { get => _timeScale; set => _timeScale = Mathf.Max(0, value); }
    
    // 事件：每游戏小时触发
    public event Action<GameDateTime> OnHourChanged;
    // 事件：昼夜交替
    public event Action<bool> OnDayNightChanged; // true = 白天
    
    private int _lastHour = -1;
    private bool _wasNight;
    
    private void Awake()
    {
        _currentTime = _startTime;
        _wasNight = _currentTime.IsNight;
    }
    
    private void Update()
    {
        if (_pauseTime) return;
        
        _accumulatedSeconds += Time.deltaTime * _timeScale;
        
        // 将现实秒数转换为游戏小时
        float gameHoursElapsed = _accumulatedSeconds / _realSecondsPerGameHour;
        _accumulatedSeconds = 0; // 全部消耗，避免精度问题
        
        AdvanceTime(gameHoursElapsed);
    }
    
    private void AdvanceTime(float hoursToAdd)
    {
        _currentTime.Minute += hoursToAdd * 60f;
        while (_currentTime.Minute >= 60f)
        {
            _currentTime.Minute -= 60f;
            _currentTime.Hour += 1f;
        }
        while (_currentTime.Hour >= 24f)
        {
            _currentTime.Hour -= 24f;
            _currentTime.Day += 1;
        }
        
        // 触发整点事件
        int currentHour = (int)_currentTime.Hour;
        if (currentHour != _lastHour)
        {
            _lastHour = currentHour;
            OnHourChanged?.Invoke(_currentTime);
        }
        
        // 触发昼夜切换事件
        bool isNightNow = _currentTime.IsNight;
        if (isNightNow != _wasNight)
        {
            _wasNight = isNightNow;
            OnDayNightChanged?.Invoke(!isNightNow);
        }
    }
    
    public void SetTime(float hour)
    {
        _currentTime.Hour = Mathf.Clamp(hour, 0f, 23.99f);
        _currentTime.Minute = 0f;
    }
    
    // 跳过到特定时间（不触发中间事件，直接跳转）
    public void SkipToTime(float targetHour)
    {
        SetTime(targetHour);
    }
}
```

### 1.2 太阳/月亮轨道模拟

```csharp
public class CelestialSystem : MonoBehaviour
{
    [Header("太阳设置")]
    [SerializeField] private Light _sunLight;
    [SerializeField] private Gradient _sunColor;
    [SerializeField] private AnimationCurve _sunIntensity;
    [SerializeField] private Transform _sunPivot;
    
    [Header("月亮设置")]
    [SerializeField] private Light _moonLight;
    [SerializeField] private Color _moonColor = new Color(0.6f, 0.7f, 1f);
    [SerializeField] private float _moonIntensityMax = 0.3f;
    
    [Header("轨道参数")]
    [SerializeField] private float _sunriseAngle = -90f;  // 日出时太阳角度（仰角）
    [SerializeField] private float _sunsetAngle = 90f;
    [SerializeField] private float _sunAzimuth = 0f;     // 方位角（东->西）
    
    private TimeSystem _timeSystem;
    
    private void Awake()
    {
        _timeSystem = GetComponent<TimeSystem>();
    }
    
    private void Update()
    {
        UpdateCelestialBodies(_timeSystem.NormalizedTime);
    }
    
    private void UpdateCelestialBodies(float normalizedTime)
    {
        // 太阳角度：0=正午（最高点），0.5/1.0=午夜（最低点）
        // normalizedTime: 0=午夜, 0.25=早6点, 0.5=正午, 0.75=晚6点
        float sunAngle = (normalizedTime - 0.25f) * 360f;
        
        // 太阳旋转
        _sunPivot.rotation = Quaternion.Euler(sunAngle, _sunAzimuth, 0f);
        
        // 太阳颜色和强度
        _sunLight.color = _sunColor.Evaluate(normalizedTime);
        _sunLight.intensity = _sunIntensity.Evaluate(normalizedTime);
        
        // 太阳在地平线以下时关闭
        float sunElevation = Vector3.Dot(_sunLight.transform.forward, Vector3.down);
        _sunLight.enabled = sunElevation > -0.1f;
        
        // 月亮和太阳相差180度
        float moonAngle = sunAngle + 180f;
        // 月亮光强：太阳越低月亮越亮
        float moonFactor = Mathf.Clamp01(-sunElevation);
        _moonLight.transform.rotation = Quaternion.Euler(moonAngle, _sunAzimuth + 180f, 0f);
        _moonLight.intensity = moonFactor * _moonIntensityMax;
        _moonLight.color = _moonColor;
        _moonLight.enabled = moonFactor > 0.01f;
        
        // 同步环境光
        RenderSettings.ambientIntensity = Mathf.Lerp(0.1f, 1f, 
            Mathf.Max(sunElevation, moonFactor * 0.3f));
    }
}
```

## 二、天气状态机

### 2.1 天气状态定义

```csharp
public enum WeatherType
{
    Clear,      // 晴朗
    Cloudy,     // 多云
    Overcast,   // 阴天
    LightRain,  // 小雨
    HeavyRain,  // 大雨
    Thunderstorm, // 雷暴
    LightSnow,  // 小雪
    HeavySnow,  // 大雪
    Fog,        // 雾
    Sandstorm,  // 沙尘暴（沙漠地图用）
}

[Serializable]
public class WeatherConfig
{
    public WeatherType Type;
    [Range(0f, 1f)] public float CloudCoverage;       // 云层覆盖率
    [Range(0f, 1f)] public float PrecipitationRate;   // 降水率
    public float FogDensity;
    public Color FogColor;
    public Color AmbientColorTint;
    [Range(0f, 1f)] public float LightningChance;     // 雷击概率/分钟
    public float WindSpeed;
    public Vector2 WindDirection;
    
    // 过渡时间（秒）
    public float TransitionDuration = 30f;
}

[CreateAssetMenu(menuName = "Weather/WeatherDatabase")]
public class WeatherDatabase : ScriptableObject
{
    public List<WeatherConfig> WeatherConfigs;
    
    // 天气转移概率矩阵（MarkovChain）
    [Serializable]
    public class TransitionRow
    {
        public WeatherType From;
        public List<WeatherTransition> Transitions;
    }
    
    [Serializable]
    public class WeatherTransition
    {
        public WeatherType To;
        [Range(0f, 1f)] public float Probability;
    }
    
    public List<TransitionRow> TransitionMatrix;
    
    public WeatherConfig GetConfig(WeatherType type)
    {
        return WeatherConfigs.Find(c => c.Type == type);
    }
    
    public WeatherType GetNextWeather(WeatherType current)
    {
        var row = TransitionMatrix.Find(r => r.From == current);
        if (row == null) return current;
        
        float rand = UnityEngine.Random.value;
        float accumulated = 0f;
        foreach (var transition in row.Transitions)
        {
            accumulated += transition.Probability;
            if (rand <= accumulated) return transition.To;
        }
        return current;
    }
}
```

### 2.2 天气状态机核心

```csharp
public class WeatherStateMachine : MonoBehaviour
{
    [SerializeField] private WeatherDatabase _database;
    [SerializeField] private WeatherType _initialWeather = WeatherType.Clear;
    [SerializeField] private float _weatherChangePeriodHours = 4f; // 每N游戏小时检查是否切换天气
    
    private WeatherType _currentWeather;
    private WeatherType _targetWeather;
    private WeatherConfig _currentConfig;
    private WeatherConfig _targetConfig;
    private float _transitionProgress; // 0-1
    private bool _isTransitioning;
    
    // 事件
    public event Action<WeatherType, WeatherType> OnWeatherTransitionStart;
    public event Action<WeatherType> OnWeatherChanged;
    
    // 各子系统引用
    private CloudSystem _cloudSystem;
    private PrecipitationSystem _precipitationSystem;
    private LightingSystem _lightingSystem;
    private LightningSystem _lightningSystem;
    
    private void Awake()
    {
        _cloudSystem = GetComponent<CloudSystem>();
        _precipitationSystem = GetComponent<PrecipitationSystem>();
        _lightingSystem = GetComponent<LightingSystem>();
        _lightningSystem = GetComponent<LightningSystem>();
        
        // 初始化天气
        SetWeatherImmediate(_initialWeather);
    }
    
    private void Start()
    {
        var timeSystem = GetComponent<TimeSystem>();
        timeSystem.OnHourChanged += OnHourChanged;
    }
    
    private void OnHourChanged(GameDateTime time)
    {
        // 每N小时随机切换天气
        if (time.Hour % _weatherChangePeriodHours < 1f)
        {
            var nextWeather = _database.GetNextWeather(_currentWeather);
            if (nextWeather != _currentWeather)
            {
                StartTransition(nextWeather);
            }
        }
    }
    
    private void Update()
    {
        if (_isTransitioning)
        {
            UpdateTransition();
        }
        
        // 雷电随机触发
        if (_currentWeather == WeatherType.Thunderstorm && _lightningSystem != null)
        {
            if (UnityEngine.Random.value < _currentConfig.LightningChance * Time.deltaTime / 60f)
            {
                _lightningSystem.TriggerLightning();
            }
        }
    }
    
    private void UpdateTransition()
    {
        float duration = _targetConfig.TransitionDuration;
        _transitionProgress += Time.deltaTime / duration;
        _transitionProgress = Mathf.Clamp01(_transitionProgress);
        
        // 插值更新各子系统
        ApplyWeatherLerp(_currentConfig, _targetConfig, _transitionProgress);
        
        if (_transitionProgress >= 1f)
        {
            _isTransitioning = false;
            _currentWeather = _targetWeather;
            _currentConfig = _targetConfig;
            OnWeatherChanged?.Invoke(_currentWeather);
        }
    }
    
    private void ApplyWeatherLerp(WeatherConfig from, WeatherConfig to, float t)
    {
        float clouds = Mathf.Lerp(from.CloudCoverage, to.CloudCoverage, t);
        float precip = Mathf.Lerp(from.PrecipitationRate, to.PrecipitationRate, t);
        float fogDensity = Mathf.Lerp(from.FogDensity, to.FogDensity, t);
        Color fogColor = Color.Lerp(from.FogColor, to.FogColor, t);
        
        _cloudSystem?.SetCoverage(clouds);
        _precipitationSystem?.SetIntensity(precip, to.Type);
        _lightingSystem?.SetFog(fogDensity, fogColor);
        _lightingSystem?.SetAmbientTint(Color.Lerp(from.AmbientColorTint, to.AmbientColorTint, t));
    }
    
    public void StartTransition(WeatherType target)
    {
        if (target == _currentWeather && !_isTransitioning) return;
        
        _targetWeather = target;
        _targetConfig = _database.GetConfig(target);
        _transitionProgress = 0f;
        _isTransitioning = true;
        
        OnWeatherTransitionStart?.Invoke(_currentWeather, _targetWeather);
    }
    
    public void SetWeatherImmediate(WeatherType weather)
    {
        _currentWeather = weather;
        _targetWeather = weather;
        _currentConfig = _database.GetConfig(weather);
        _transitionProgress = 1f;
        _isTransitioning = false;
        
        ApplyWeatherLerp(_currentConfig, _currentConfig, 1f);
    }
}
```

### 3.1 粒子系统驱动的降雨

```csharp
public class PrecipitationSystem : MonoBehaviour
{
    [Header("雨效果")]
    [SerializeField] private ParticleSystem _rainParticles;
    [SerializeField] private ParticleSystem _rainSplashParticles;
    [SerializeField] private AudioSource _rainAudio;
    [SerializeField] private Material _wetGroundMaterial;
    
    [Header("雪效果")]
    [SerializeField] private ParticleSystem _snowParticles;
    [SerializeField] private Material _snowGroundMaterial;
    
    [Header("跟随相机")]
    [SerializeField] private bool _followCamera = true;
    [SerializeField] private float _spawnRadius = 30f;
    [SerializeField] private float _spawnHeight = 25f;
    
    private Camera _mainCamera;
    private WeatherType _currentPrecipType;
    private float _currentIntensity;
    
    private static readonly int WetFactor = Shader.PropertyToID("_WetFactor");
    private static readonly int SnowFactor = Shader.PropertyToID("_SnowFactor");
    
    private void Awake()
    {
        _mainCamera = Camera.main;
        StopAll();
    }
    
    private void Update()
    {
        if (_followCamera && _mainCamera != null)
        {
            // 粒子系统跟随相机，确保覆盖玩家周围区域
            Vector3 camPos = _mainCamera.transform.position;
            transform.position = new Vector3(camPos.x, camPos.y + _spawnHeight, camPos.z);
        }
    }
    
    public void SetIntensity(float intensity, WeatherType precipType)
    {
        _currentIntensity = intensity;
        _currentPrecipType = precipType;
        
        bool isRain = precipType == WeatherType.LightRain || 
                      precipType == WeatherType.HeavyRain ||
                      precipType == WeatherType.Thunderstorm;
        bool isSnow = precipType == WeatherType.LightSnow || 
                      precipType == WeatherType.HeavySnow;
        
        if (intensity < 0.01f)
        {
            StopAll();
            return;
        }
        
        if (isRain) UpdateRain(intensity);
        if (isSnow) UpdateSnow(intensity);
        
        // 更新地面湿润/积雪效果
        UpdateGroundShaders(isRain ? intensity : 0f, isSnow ? intensity : 0f);
    }
    
    private void UpdateRain(float intensity)
    {
        if (!_rainParticles.isPlaying) _rainParticles.Play();
        if (_snowParticles.isPlaying) _snowParticles.Stop();
        
        var main = _rainParticles.main;
        main.maxParticles = (int)Mathf.Lerp(500, 5000, intensity);
        
        var emission = _rainParticles.emission;
        emission.rateOverTime = Mathf.Lerp(100, 2000, intensity);
        
        // 雨声音量
        if (_rainAudio != null)
        {
            _rainAudio.volume = Mathf.Lerp(0.1f, 1f, intensity);
            if (!_rainAudio.isPlaying) _rainAudio.Play();
        }
    }
    
    private void UpdateSnow(float intensity)
    {
        if (_rainParticles.isPlaying) _rainParticles.Stop();
        if (!_snowParticles.isPlaying) _snowParticles.Play();
        
        var main = _snowParticles.main;
        main.maxParticles = (int)Mathf.Lerp(200, 3000, intensity);
        
        var emission = _snowParticles.emission;
        emission.rateOverTime = Mathf.Lerp(50, 1000, intensity);
    }
    
    private void UpdateGroundShaders(float wetFactor, float snowFactor)
    {
        if (_wetGroundMaterial != null)
            _wetGroundMaterial.SetFloat(WetFactor, Mathf.Lerp(
                _wetGroundMaterial.GetFloat(WetFactor), wetFactor, Time.deltaTime * 0.5f));
        
        if (_snowGroundMaterial != null)
            _snowGroundMaterial.SetFloat(SnowFactor, Mathf.Lerp(
                _snowGroundMaterial.GetFloat(SnowFactor), snowFactor, Time.deltaTime * 0.1f));
    }
    
    private void StopAll()
    {
        _rainParticles?.Stop();
        _snowParticles?.Stop();
        _rainSplashParticles?.Stop();
        if (_rainAudio != null && _rainAudio.isPlaying)
            _rainAudio.Stop();
    }
}
```

## 四、地面湿润Shader（URP）

```hlsl
// WetGround.shader - URP地面湿润效果
Shader "Custom/WetGround"
{
    Properties
    {
        _BaseMap ("Albedo", 2D) = "white" {}
        _NormalMap ("Normal Map", 2D) = "bump" {}
        _WetFactor ("Wet Factor", Range(0, 1)) = 0
        _WaterColor ("Water Color", Color) = (0.1, 0.15, 0.2, 1)
        _WaterRoughness ("Water Roughness", Range(0, 1)) = 0.05
        _PuddleThreshold ("Puddle Threshold", Range(0, 1)) = 0.3
    }
    
    SubShader
    {
        Tags { "RenderType"="Opaque" "RenderPipeline"="UniversalPipeline" }
        
        Pass
        {
            Name "ForwardLit"
            Tags { "LightMode"="UniversalForward" }
            
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag
            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"
            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Lighting.hlsl"
            
            TEXTURE2D(_BaseMap); SAMPLER(sampler_BaseMap);
            TEXTURE2D(_NormalMap); SAMPLER(sampler_NormalMap);
            
            CBUFFER_START(UnityPerMaterial)
                float4 _BaseMap_ST;
                float _WetFactor;
                float4 _WaterColor;
                float _WaterRoughness;
                float _PuddleThreshold;
            CBUFFER_END
            
            struct Attributes {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
                float3 normalOS : NORMAL;
                float4 tangentOS : TANGENT;
            };
            
            struct Varyings {
                float4 positionCS : SV_POSITION;
                float2 uv : TEXCOORD0;
                float3 positionWS : TEXCOORD1;
                float3 normalWS : TEXCOORD2;
                float4 tangentWS : TEXCOORD3;
            };
            
            Varyings vert(Attributes IN)
            {
                Varyings OUT;
                OUT.positionCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.positionWS = TransformObjectToWorld(IN.positionOS.xyz);
                OUT.uv = TRANSFORM_TEX(IN.uv, _BaseMap);
                OUT.normalWS = TransformObjectToWorldNormal(IN.normalOS);
                OUT.tangentWS = float4(TransformObjectToWorldDir(IN.tangentOS.xyz), IN.tangentOS.w);
                return OUT;
            }
            
            half4 frag(Varyings IN) : SV_Target
            {
                float2 uv = IN.uv;
                half4 baseColor = SAMPLE_TEXTURE2D(_BaseMap, sampler_BaseMap, uv);
                half3 normalTS = UnpackNormal(SAMPLE_TEXTURE2D(_NormalMap, sampler_NormalMap, uv));
                
                // 水洼遮罩：法线朝上的区域更容易积水
                float upFactor = saturate(dot(normalize(IN.normalWS), float3(0, 1, 0)));
                float puddleMask = smoothstep(_PuddleThreshold, _PuddleThreshold + 0.2, upFactor);
                float wetAmount = _WetFactor * puddleMask;
                
                // 湿润效果：颜色变深、粗糙度降低
                half3 dryColor = baseColor.rgb;
                half3 wetColor = lerp(dryColor, dryColor * 0.6, wetAmount);   // 湿润后颜色加深
                wetColor = lerp(wetColor, _WaterColor.rgb, wetAmount * 0.3);  // 混合水色
                
                // 法线：湿润区域法线趋向水平（积水变光滑）
                float3 waterNormal = float3(0, 0, 1);
                normalTS = lerp(normalTS, waterNormal, wetAmount * 0.8);
                
                // 金属度和粗糙度
                float metallic = 0;
                float roughness = lerp(0.9, _WaterRoughness, wetAmount);
                
                // 构建切线空间法线到世界空间
                float3 bitangentWS = cross(IN.normalWS, IN.tangentWS.xyz) * IN.tangentWS.w;
                float3x3 TBN = float3x3(IN.tangentWS.xyz, bitangentWS, IN.normalWS);
                float3 normalWS = TransformTangentToWorld(normalTS, TBN);
                
                // PBR光照（简化）
                InputData inputData = (InputData)0;
                inputData.positionWS = IN.positionWS;
                inputData.normalWS = normalize(normalWS);
                inputData.viewDirectionWS = GetWorldSpaceNormalizeViewDir(IN.positionWS);
                
                SurfaceData surfaceData = (SurfaceData)0;
                surfaceData.albedo = wetColor;
                surfaceData.metallic = metallic;
                surfaceData.smoothness = 1 - roughness;
                surfaceData.alpha = 1;
                
                return UniversalFragmentPBR(inputData, surfaceData);
            }
            ENDHLSL
        }
    }
}
```

## 五、雷电系统

```csharp
public class LightningSystem : MonoBehaviour
{
    [Header("雷电闪光")]
    [SerializeField] private Light _lightningLight;
    [SerializeField] private float _flashDuration = 0.15f;
    [SerializeField] private AnimationCurve _flashCurve;
    
    [Header("雷声")]
    [SerializeField] private AudioSource _thunderAudio;
    [SerializeField] private AudioClip[] _thunderClips;
    [SerializeField] private float _soundDelayPerUnit = 0.003f; // 每单位距离延迟（秒）
    
    [Header("闪电视觉")]
    [SerializeField] private LineRenderer _lightningBoltPrefab;
    [SerializeField] private int _strikePoints = 12;
    [SerializeField] private float _jitterAmount = 2f;
    
    private Coroutine _flashCoroutine;
    private Camera _mainCamera;
    
    private void Awake()
    {
        _mainCamera = Camera.main;
        if (_lightningLight != null) _lightningLight.intensity = 0;
    }
    
    public void TriggerLightning()
    {
        // 随机选择闪击点（玩家周围一定范围）
        Vector3 strikePos = GetRandomStrikePosition();
        
        // 闪光效果
        if (_flashCoroutine != null) StopCoroutine(_flashCoroutine);
        _flashCoroutine = StartCoroutine(LightningFlash(strikePos));
        
        // 绘制闪电线条
        DrawLightningBolt(transform.position + Vector3.up * 50, strikePos);
    }
    
    private Vector3 GetRandomStrikePosition()
    {
        if (_mainCamera == null) return transform.position;
        Vector3 camPos = _mainCamera.transform.position;
        Vector2 randomXZ = UnityEngine.Random.insideUnitCircle * 100f;
        return new Vector3(camPos.x + randomXZ.x, 0, camPos.z + randomXZ.y);
    }
    
    private IEnumerator LightningFlash(Vector3 strikePos)
    {
        if (_lightningLight == null) yield break;
        
        float elapsed = 0f;
        float maxIntensity = UnityEngine.Random.Range(8f, 20f);
        
        while (elapsed < _flashDuration)
        {
            elapsed += Time.deltaTime;
            float t = elapsed / _flashDuration;
            _lightningLight.intensity = _flashCurve.Evaluate(t) * maxIntensity;
            yield return null;
        }
        _lightningLight.intensity = 0f;
        
        // 延迟播放雷声（光速 vs 声速）
        float distance = Vector3.Distance(_mainCamera.transform.position, strikePos);
        float delay = distance * _soundDelayPerUnit;
        yield return new WaitForSeconds(delay);
        
        PlayThunder();
    }
    
    private void PlayThunder()
    {
        if (_thunderAudio == null || _thunderClips.Length == 0) return;
        var clip = _thunderClips[UnityEngine.Random.Range(0, _thunderClips.Length)];
        _thunderAudio.pitch = UnityEngine.Random.Range(0.85f, 1.15f);
        _thunderAudio.PlayOneShot(clip);
    }
    
    private void DrawLightningBolt(Vector3 from, Vector3 to)
    {
        if (_lightningBoltPrefab == null) return;
        
        var bolt = Instantiate(_lightningBoltPrefab);
        bolt.positionCount = _strikePoints;
        
        for (int i = 0; i < _strikePoints; i++)
        {
            float t = (float)i / (_strikePoints - 1);
            Vector3 pos = Vector3.Lerp(from, to, t);
            if (i > 0 && i < _strikePoints - 1)
            {
                pos += new Vector3(
                    UnityEngine.Random.Range(-_jitterAmount, _jitterAmount),
                    0,
                    UnityEngine.Random.Range(-_jitterAmount, _jitterAmount)
                );
            }
            bolt.SetPosition(i, pos);
        }
        
        Destroy(bolt.gameObject, 0.2f); // 短暂显示后消失
    }
}
```

## 八、最佳实践总结

| 方面 | 建议 |
|------|------|
| **性能** | 粒子系统跟随相机，超出视野的粒子尽早回收；分级渲染适配中低端设备 |
| **一致性** | 所有子系统通过统一的WeatherEventBus通信，避免直接引用耦合 |
| **过渡** | 天气切换至少30秒过渡时间，避免突变；雾效使用插值而非瞬切 |
| **音频** | 雨声/风声分层混音（轻雨+背景风+雷声单独通道），根据强度动态调整 |
| **存档** | 保存当前天气状态和游戏时间，恢复时重建天气状态 |
| **调试** | 提供Inspector实时调节时间/天气的Debug面板，方便关卡策划测试 |
| **扩展** | 使用ScriptableObject配置天气参数，策划可不经程序自行添加天气类型 |

## 结语

动态天气与昼夜循环系统是提升游戏世界真实感的重要基础设施。通过合理的状态机设计、事件总线解耦、分级渲染策略，可以在各平台上高效运行。关键在于：**物理真实感与性能的平衡**、**各子系统的解耦协作**、以及**给策划/美术足够的调节空间**。
