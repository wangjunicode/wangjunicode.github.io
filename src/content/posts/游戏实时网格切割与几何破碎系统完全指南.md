# 游戏实时网格切割与几何破碎系统完全指南

## 一、网格切割的应用场景与算法概述

### 1.1 游戏中的切割需求

实时网格切割技术在游戏中有广泛应用场景：
- **近战战斗**：剑气、刀刃切割敌人/环境物体
- **环境破坏**：炸弹爆炸、子弹穿透、技能破坏地形
- **料理/手术游戏**：精确切割模拟
- **演出特效**：光剑切割、能量波斩击

### 1.2 主要切割算法对比

| 算法 | 原理 | 优点 | 缺点 | 适用场景 |
|------|------|------|------|----------|
| 平面切割（Plane Cut） | 用平面将Mesh一分为二 | 精确、无损耗 | 仅支持单次直线切割 | 剑气、刀刃切割 |
| Voronoi破碎 | 预计算碎片，运行时拼接 | 高性能 | 碎片预设，不支持任意切割 | 爆炸、冲击破坏 |
| BSP树切割 | 二叉空间分割递归切割 | 支持复杂切割路径 | 实现复杂 | 复杂几何切割 |
| SDF体素化 | 转换为体素后切割重建 | 支持任意形状切割 | 性能开销大 | 软体/流体切割 |

## 二、平面切割算法核心实现

### 2.1 切割面数学定义

```csharp
using UnityEngine;
using System.Collections.Generic;

/// <summary>
/// 切割平面定义
/// </summary>
public struct CutPlane
{
    public Vector3 Point;   // 平面上一点
    public Vector3 Normal;  // 平面法线（单位向量）

    public CutPlane(Vector3 point, Vector3 normal)
    {
        Point  = point;
        Normal = normal.normalized;
    }

    /// <summary>
    /// 判断点在平面哪一侧
    /// 返回值 > 0：正面；< 0：背面；≈ 0：在平面上
    /// </summary>
    public float GetSide(Vector3 point)
    {
        return Vector3.Dot(Normal, point - Point);
    }

    /// <summary>
    /// 计算线段与平面的交点
    /// </summary>
    public bool Intersect(Vector3 a, Vector3 b, out Vector3 intersection, out float t)
    {
        Vector3 ab = b - a;
        float denom = Vector3.Dot(Normal, ab);
        
        if (Mathf.Abs(denom) < 1e-6f)
        {
            intersection = Vector3.zero;
            t = 0f;
            return false; // 线段平行于平面
        }
        
        t = Vector3.Dot(Normal, Point - a) / denom;
        intersection = a + ab * t;
        return t >= 0f && t <= 1f;
    }
}
```

### 2.2 三角形切割核心算法

```csharp
/// <summary>
/// 网格切割器核心算法
/// </summary>
public static class MeshCutter
{
    private const float EPSILON = 1e-6f;

    /// <summary>
    /// 切割网格，返回正面和背面两个子网格
    /// </summary>
    public static bool Cut(
        Mesh originalMesh, 
        CutPlane cutPlane,
        out Mesh positiveMesh, 
        out Mesh negativeMesh,
        Material capMaterial = null)
    {
        positiveMesh = null;
        negativeMesh = null;

        // 获取原始顶点数据
        Vector3[] vertices  = originalMesh.vertices;
        Vector3[] normals   = originalMesh.normals;
        Vector2[] uvs       = originalMesh.uv;
        int[]     triangles = originalMesh.triangles;

        // 两侧的顶点/三角形收集器
        var posBuilder = new MeshBuilder();
        var negBuilder = new MeshBuilder();

        // 切割截面顶点（用于生成截面Cap）
        var capVertices = new List<Vector3>();

        int triCount = triangles.Length / 3;
        
        for (int t = 0; t < triCount; t++)
        {
            int i0 = triangles[t * 3 + 0];
            int i1 = triangles[t * 3 + 1];
            int i2 = triangles[t * 3 + 2];

            var v0 = new VertexData(vertices[i0], 
                normals.Length > 0 ? normals[i0] : Vector3.up, 
                uvs.Length > 0     ? uvs[i0]     : Vector2.zero);
            var v1 = new VertexData(vertices[i1], 
                normals.Length > 0 ? normals[i1] : Vector3.up,
                uvs.Length > 0     ? uvs[i1]     : Vector2.zero);
            var v2 = new VertexData(vertices[i2],
                normals.Length > 0 ? normals[i2] : Vector3.up,
                uvs.Length > 0     ? uvs[i2]     : Vector2.zero);

            float d0 = cutPlane.GetSide(v0.Position);
            float d1 = cutPlane.GetSide(v1.Position);
            float d2 = cutPlane.GetSide(v2.Position);

            bool pos0 = d0 >= -EPSILON;
            bool pos1 = d1 >= -EPSILON;
            bool pos2 = d2 >= -EPSILON;

            // 整个三角形在同一侧
            if (pos0 && pos1 && pos2) { posBuilder.AddTriangle(v0, v1, v2); continue; }
            if (!pos0 && !pos1 && !pos2) { negBuilder.AddTriangle(v0, v1, v2); continue; }

            // 三角形跨越切割面，需要分割
            SplitTriangle(v0, v1, v2, d0, d1, d2, pos0, pos1, pos2,
                cutPlane, posBuilder, negBuilder, capVertices);
        }

        // 生成截面（填充切口）
        if (capVertices.Count >= 3)
        {
            GenerateCap(capVertices, cutPlane.Normal, posBuilder, negBuilder);
        }

        positiveMesh = posBuilder.Build();
        negativeMesh = negBuilder.Build();

        return positiveMesh.vertexCount > 0 && negativeMesh.vertexCount > 0;
    }

    static void SplitTriangle(
        VertexData v0, VertexData v1, VertexData v2,
        float d0, float d1, float d2,
        bool pos0, bool pos1, bool pos2,
        CutPlane plane,
        MeshBuilder posBuilder, MeshBuilder negBuilder,
        List<Vector3> capVertices)
    {
        // 找出孤立顶点（在少数侧的顶点）
        // 情况1：1个正面，2个负面
        // 情况2：2个正面，1个负面

        // 统一处理：先重排使v0为孤立顶点
        if (pos0 == pos1) // v2孤立
        {
            SplitTriangleSingleIsolated(v2, v0, v1, d2, d0, d1, pos2, plane, posBuilder, negBuilder, capVertices);
        }
        else if (pos1 == pos2) // v0孤立
        {
            SplitTriangleSingleIsolated(v0, v1, v2, d0, d1, d2, pos0, plane, posBuilder, negBuilder, capVertices);
        }
        else // v1孤立
        {
            SplitTriangleSingleIsolated(v1, v2, v0, d1, d2, d0, pos1, plane, posBuilder, negBuilder, capVertices);
        }
    }

    /// <summary>
    /// 处理v_iso孤立、v_a和v_b同侧的情况
    /// </summary>
    static void SplitTriangleSingleIsolated(
        VertexData v_iso, VertexData v_a, VertexData v_b,
        float d_iso, float d_a, float d_b,
        bool iso_positive,
        CutPlane plane,
        MeshBuilder posBuilder, MeshBuilder negBuilder,
        List<Vector3> capVertices)
    {
        // 计算边 iso→a 和 iso→b 与切割面的交点
        float t_ia = d_iso / (d_iso - d_a);
        float t_ib = d_iso / (d_iso - d_b);

        VertexData v_ia = VertexData.Lerp(v_iso, v_a, t_ia);
        VertexData v_ib = VertexData.Lerp(v_iso, v_b, t_ib);

        // 收集截面顶点
        capVertices.Add(v_ia.Position);
        capVertices.Add(v_ib.Position);

        if (iso_positive)
        {
            // 孤立顶点在正面：正面1个三角形，负面2个三角形
            posBuilder.AddTriangle(v_iso, v_ia, v_ib);
            negBuilder.AddTriangle(v_ia, v_a, v_ib);
            negBuilder.AddTriangle(v_a, v_b, v_ib);
        }
        else
        {
            // 孤立顶点在负面：负面1个三角形，正面2个三角形
            negBuilder.AddTriangle(v_iso, v_ia, v_ib);
            posBuilder.AddTriangle(v_ia, v_a, v_ib);
            posBuilder.AddTriangle(v_a, v_b, v_ib);
        }
    }

    /// <summary>
    /// 生成切割截面（将切口填充为封闭几何体）
    /// </summary>
    static void GenerateCap(
        List<Vector3> capVertices, 
        Vector3 cutNormal,
        MeshBuilder posBuilder, 
        MeshBuilder negBuilder)
    {
        if (capVertices.Count < 3) return;

        // 计算截面中心
        Vector3 center = Vector3.zero;
        foreach (var v in capVertices)
            center += v;
        center /= capVertices.Count;

        // 构建局部坐标系
        Vector3 right = Vector3.Cross(cutNormal, 
            Mathf.Abs(cutNormal.y) < 0.9f ? Vector3.up : Vector3.right).normalized;
        Vector3 up = Vector3.Cross(right, cutNormal);

        // 计算极角排序
        var sortedVerts = new List<(Vector3 pos, float angle)>();
        foreach (var v in capVertices)
        {
            Vector3 dir = v - center;
            float angle = Mathf.Atan2(Vector3.Dot(dir, up), Vector3.Dot(dir, right));
            sortedVerts.Add((v, angle));
        }
        sortedVerts.Sort((a, b) => a.angle.CompareTo(b.angle));

        // 扇形三角剖分
        for (int i = 0; i < sortedVerts.Count; i++)
        {
            int next = (i + 1) % sortedVerts.Count;
            
            Vector3 a = sortedVerts[i].pos;
            Vector3 b = sortedVerts[next].pos;

            // 正面截面（法线朝向正面）
            var capV_center = new VertexData(center, cutNormal, 
                new Vector2(0.5f, 0.5f));
            var capV_a = new VertexData(a, cutNormal, 
                new Vector2(Vector3.Dot(a - center, right) * 0.5f + 0.5f,
                            Vector3.Dot(a - center, up)    * 0.5f + 0.5f));
            var capV_b = new VertexData(b, cutNormal, 
                new Vector2(Vector3.Dot(b - center, right) * 0.5f + 0.5f,
                            Vector3.Dot(b - center, up)    * 0.5f + 0.5f));

            posBuilder.AddTriangle(capV_center, capV_a, capV_b);

            // 负面截面（法线反向）
            var capV_center_neg = new VertexData(center, -cutNormal, new Vector2(0.5f, 0.5f));
            var capV_a_neg      = new VertexData(a, -cutNormal, capV_a.UV);
            var capV_b_neg      = new VertexData(b, -cutNormal, capV_b.UV);

            negBuilder.AddTriangle(capV_center_neg, capV_b_neg, capV_a_neg);
        }
    }
}
```

### 2.3 顶点数据与Mesh构建器

```csharp
/// <summary>
/// 顶点数据结构（含插值支持）
/// </summary>
public struct VertexData
{
    public Vector3 Position;
    public Vector3 Normal;
    public Vector2 UV;

    public VertexData(Vector3 pos, Vector3 normal, Vector2 uv)
    {
        Position = pos;
        Normal   = normal;
        UV       = uv;
    }

    public static VertexData Lerp(VertexData a, VertexData b, float t)
    {
        return new VertexData(
            Vector3.Lerp(a.Position, b.Position, t),
            Vector3.Slerp(a.Normal,  b.Normal,   t).normalized,
            Vector2.Lerp(a.UV,       b.UV,        t)
        );
    }
}

/// <summary>
/// Mesh数据收集器，使用字典去重顶点
/// </summary>
public class MeshBuilder
{
    private readonly List<Vector3> m_Positions = new List<Vector3>();
    private readonly List<Vector3> m_Normals   = new List<Vector3>();
    private readonly List<Vector2> m_UVs       = new List<Vector2>();
    private readonly List<int>     m_Triangles = new List<int>();
    
    // 顶点复用表（简化版，精确比较）
    private readonly Dictionary<(Vector3, Vector3, Vector2), int> m_VertexMap
        = new Dictionary<(Vector3, Vector3, Vector2), int>();

    public void AddTriangle(VertexData v0, VertexData v1, VertexData v2)
    {
        m_Triangles.Add(GetOrAddVertex(v0));
        m_Triangles.Add(GetOrAddVertex(v1));
        m_Triangles.Add(GetOrAddVertex(v2));
    }

    int GetOrAddVertex(VertexData v)
    {
        var key = (v.Position, v.Normal, v.UV);
        if (m_VertexMap.TryGetValue(key, out int idx))
            return idx;
        
        idx = m_Positions.Count;
        m_Positions.Add(v.Position);
        m_Normals.Add(v.Normal);
        m_UVs.Add(v.UV);
        m_VertexMap[key] = idx;
        return idx;
    }

    public Mesh Build()
    {
        var mesh = new Mesh
        {
            name = "CutMesh_" + System.Guid.NewGuid().ToString("N").Substring(0, 8)
        };
        
        if (m_Positions.Count > 65535)
            mesh.indexFormat = UnityEngine.Rendering.IndexFormat.UInt32;
        
        mesh.SetVertices(m_Positions);
        mesh.SetNormals(m_Normals);
        mesh.SetUVs(0, m_UVs);
        mesh.SetTriangles(m_Triangles, 0);
        mesh.RecalculateBounds();
        mesh.RecalculateTangents();
        
        return mesh;
    }
}
```

### 3.1 可切割对象组件

```csharp
using UnityEngine;
using System.Collections;
using System.Collections.Generic;

/// <summary>
/// 可被实时切割的游戏对象组件
/// </summary>
[RequireComponent(typeof(MeshFilter), typeof(MeshRenderer), typeof(MeshCollider))]
public class CuttableObject : MonoBehaviour
{
    [Header("切割配置")]
    [SerializeField] private int   m_MaxCutCount = 3;          // 最大切割次数
    [SerializeField] private float m_MinFragmentVolume = 0.01f; // 碎片最小体积阈值（小于则销毁）
    [SerializeField] private float m_FragmentLifetime = 8f;     // 碎片存活时长
    
    [Header("物理参数")]
    [SerializeField] private float m_CutForce     = 5f;   // 切割冲击力
    [SerializeField] private float m_FragmentMass = 0.5f; // 碎片质量
    
    [Header("材质")]
    [SerializeField] private Material m_CapMaterial; // 切面材质
    [SerializeField] private bool     m_UseSharedCapMaterial = true;

    [Header("特效")]
    [SerializeField] private GameObject m_CutEffectPrefab;
    [SerializeField] private AudioClip  m_CutSound;

    private int        m_CutCount = 0;
    private MeshFilter m_MeshFilter;
    private AudioSource m_AudioSource;

    void Awake()
    {
        m_MeshFilter    = GetComponent<MeshFilter>();
        m_AudioSource   = GetComponent<AudioSource>();
    }

    /// <summary>
    /// 执行切割，由外部（剑气/子弹等）调用
    /// </summary>
    public bool TryCut(Vector3 contactPoint, Vector3 cutNormal, Vector3 cutForceDir)
    {
        if (m_CutCount >= m_MaxCutCount)
        {
            Debug.Log($"[CuttableObject] {name} 已达最大切割次数");
            return false;
        }

        // 将切割平面转换到本地坐标系
        Vector3 localPoint  = transform.InverseTransformPoint(contactPoint);
        Vector3 localNormal = transform.InverseTransformDirection(cutNormal).normalized;
        
        var cutPlane = new CutPlane(localPoint, localNormal);
        
        // 执行网格切割
        bool success = MeshCutter.Cut(
            m_MeshFilter.mesh, 
            cutPlane,
            out Mesh posMesh, 
            out Mesh negMesh,
            m_CapMaterial);

        if (!success)
        {
            Debug.Log($"[CuttableObject] 切割失败（对象可能太小或切割面不相交）");
            return false;
        }

        m_CutCount++;

        // 播放特效音效
        PlayCutEffects(contactPoint);

        // 创建两个碎片
        SpawnFragment(posMesh, cutForceDir, isPositiveSide: true);
        SpawnFragment(negMesh, -cutForceDir, isPositiveSide: false);

        // 销毁原对象
        Destroy(gameObject);
        return true;
    }

    void SpawnFragment(Mesh fragmentMesh, Vector3 forceDir, bool isPositiveSide)
    {
        // 体积检测，丢弃太小的碎片
        Bounds bounds = fragmentMesh.bounds;
        float volume  = bounds.size.x * bounds.size.y * bounds.size.z;
        
        if (volume < m_MinFragmentVolume)
        {
            Debug.Log($"[CuttableObject] 碎片体积({volume:F4})过小，已丢弃");
            return;
        }

        // 创建碎片GameObject
        var fragment = new GameObject($"{name}_Fragment_{(isPositiveSide ? "Pos" : "Neg")}");
        fragment.transform.SetPositionAndRotation(transform.position, transform.rotation);
        fragment.transform.localScale = transform.lossyScale;
        fragment.layer = gameObject.layer;
        fragment.tag   = "Fragment";

        // MeshFilter + MeshRenderer
        var mf = fragment.AddComponent<MeshFilter>();
        var mr = fragment.AddComponent<MeshRenderer>();
        mf.mesh = fragmentMesh;
        
        // 复制材质：原材质 + 截面材质
        var originalMats = GetComponent<MeshRenderer>().sharedMaterials;
        var fragMats = new Material[originalMats.Length + 1];
        System.Array.Copy(originalMats, fragMats, originalMats.Length);
        fragMats[fragMats.Length - 1] = m_CapMaterial;
        mr.materials = fragMats;

        // 设置子Mesh对应的材质索引（截面使用最后一个材质槽）
        fragmentMesh.subMeshCount = 2;
        // 注意：完整实现需要在切割时分离截面三角形到subMesh[1]
        
        // MeshCollider（凸包，性能更好）
        var mc = fragment.AddComponent<MeshCollider>();
        mc.sharedMesh = fragmentMesh;
        mc.convex     = true;

        // Rigidbody物理
        var rb = fragment.AddComponent<Rigidbody>();
        rb.mass        = m_FragmentMass * volume;
        rb.linearDamping       = 0.5f;
        rb.angularDamping      = 1f;
        
        // 施加切割冲击力
        Vector3 worldForce = transform.TransformDirection(forceDir) * m_CutForce;
        rb.AddForce(worldForce, ForceMode.Impulse);
        rb.AddTorque(Random.insideUnitSphere * m_CutForce * 0.5f, ForceMode.Impulse);

        // 允许继续切割
        if (m_CutCount < m_MaxCutCount)
        {
            var cuttable = fragment.AddComponent<CuttableObject>();
            cuttable.m_MaxCutCount          = m_MaxCutCount - m_CutCount;
            cuttable.m_MinFragmentVolume    = m_MinFragmentVolume;
            cuttable.m_CapMaterial          = m_CapMaterial;
            cuttable.m_CutEffectPrefab      = m_CutEffectPrefab;
            cuttable.m_FragmentLifetime     = m_FragmentLifetime;
        }

        // 定时销毁碎片
        Destroy(fragment, m_FragmentLifetime);
    }

    void PlayCutEffects(Vector3 position)
    {
        if (m_CutEffectPrefab != null)
        {
            var effect = Instantiate(m_CutEffectPrefab, position, Quaternion.identity);
            Destroy(effect, 3f);
        }

        if (m_AudioSource != null && m_CutSound != null)
        {
            m_AudioSource.PlayOneShot(m_CutSound);
        }
    }
}
```

## 四、剑气切割检测系统

### 4.1 剑挥轨迹采样与切割面计算

```csharp
using UnityEngine;
using System.Collections.Generic;

/// <summary>
/// 剑气切割检测器
/// 通过追踪剑尖和剑根的轨迹，计算切割平面，检测可切割对象
/// </summary>
public class SlashCutter : MonoBehaviour
{
    [Header("剑体参考点")]
    [SerializeField] private Transform m_BladeRoot; // 护手位置
    [SerializeField] private Transform m_BladeTip;  // 剑尖位置
    
    [Header("切割参数")]
    [SerializeField] private float m_MinSlashSpeed    = 3f;   // 最小切割速度
    [SerializeField] private float m_SlashRadius      = 0.1f; // 切割射线半径
    [SerializeField] private LayerMask m_CuttableMask;

    [Header("Trail")]
    [SerializeField] private TrailRenderer m_BladeTrail;

    // 轨迹历史（用于计算切割平面）
    private readonly List<(Vector3 root, Vector3 tip, float time)> m_TrailHistory
        = new List<(Vector3, Vector3, float)>(16);
    
    private Vector3 m_LastRootPos;
    private Vector3 m_LastTipPos;
    private bool    m_IsAttacking = false;
    private float   m_AttackStartTime;

    public void BeginAttack()
    {
        m_IsAttacking    = true;
        m_AttackStartTime = Time.time;
        m_TrailHistory.Clear();
        
        if (m_BladeTrail != null)
        {
            m_BladeTrail.enabled   = true;
            m_BladeTrail.Clear();
        }
        
        m_LastRootPos = m_BladeRoot.position;
        m_LastTipPos  = m_BladeTip.position;
    }

    public void EndAttack()
    {
        m_IsAttacking = false;
        if (m_BladeTrail != null)
            m_BladeTrail.enabled = false;
    }

    void FixedUpdate()
    {
        if (!m_IsAttacking) return;
        
        Vector3 rootPos = m_BladeRoot.position;
        Vector3 tipPos  = m_BladeTip.position;

        // 记录轨迹
        m_TrailHistory.Add((rootPos, tipPos, Time.time));
        if (m_TrailHistory.Count > 10)
            m_TrailHistory.RemoveAt(0);

        // 计算本帧挥动速度
        float tipSpeed = (tipPos - m_LastTipPos).magnitude / Time.fixedDeltaTime;
        
        if (tipSpeed >= m_MinSlashSpeed)
        {
            PerformCutDetection(rootPos, tipPos, m_LastRootPos, m_LastTipPos);
        }

        m_LastRootPos = rootPos;
        m_LastTipPos  = tipPos;
    }

    void PerformCutDetection(
        Vector3 currentRoot, Vector3 currentTip,
        Vector3 lastRoot,    Vector3 lastTip)
    {
        // 切割平面由4个点定义（当前帧和上一帧的剑身）
        // 法线 = (当前剑身方向) × (剑移动方向)
        Vector3 bladeDir   = (currentTip - currentRoot).normalized;
        Vector3 moveDir    = (currentTip - lastTip).normalized;
        Vector3 cutNormal  = Vector3.Cross(bladeDir, moveDir).normalized;

        if (cutNormal.sqrMagnitude < 0.01f) return; // 退化情况

        // 切割平面中心点
        Vector3 cutCenter = (currentRoot + currentTip + lastRoot + lastTip) * 0.25f;

        // 沿剑身方向执行多条射线检测
        int rayCount = 5;
        for (int i = 0; i < rayCount; i++)
        {
            float t = i / (float)(rayCount - 1);
            Vector3 rayOrigin = Vector3.Lerp(currentRoot, currentTip, t);
            Vector3 rayDir    = (Vector3.Lerp(lastRoot, lastTip, t) - rayOrigin).normalized;
            float   rayLen    = Vector3.Distance(
                Vector3.Lerp(lastRoot, lastTip, t), rayOrigin);

            if (rayLen < 0.001f) continue;

            // SphereCast 检测可切割对象
            if (Physics.SphereCast(rayOrigin, m_SlashRadius, rayDir, 
                out RaycastHit hit, rayLen, m_CuttableMask))
            {
                var cuttable = hit.collider.GetComponent<CuttableObject>();
                if (cuttable != null)
                {
                    // 切割方向 = 剑移动方向的投影（去除法线分量）
                    Vector3 forceDir = Vector3.ProjectOnPlane(moveDir, cutNormal).normalized;
                    
                    bool cutSuccess = cuttable.TryCut(
                        hit.point, 
                        cutNormal, 
                        forceDir * (currentTip - lastTip).magnitude / Time.fixedDeltaTime);
                    
                    if (cutSuccess)
                    {
                        Debug.Log($"[SlashCutter] 成功切割：{hit.collider.name}");
                        // 同一帧防止重复切割同一对象（对象已销毁）
                        break;
                    }
                }
            }
        }
    }
}
```

```csharp
public class PreFragmentedObject : MonoBehaviour

        // 初始隐藏所有碎片

        {
            if (fragment != null)
            {
                fragment.SetActive(false);
                // 禁用Rigidbody直到破碎
                var rb = fragment.GetComponent<Rigidbody>();
                if (rb != null) rb.isKinematic = true;
            }
        }
        
        if (m_WholeObject != null)
            m_WholeObject.SetActive(true);
    }

    /// <summary>
    /// 触发破碎（由外部调用：爆炸、子弹命中等）
    /// </summary>
    public void Break(Vector3 explosionCenter, float forceMagnitude = -1f)
    {
        if (m_IsBroken) return;
        m_IsBroken = true;
        
        float force = forceMagnitude > 0 ? forceMagnitude : m_ExplosionForce;
        
        // 隐藏完整体
        if (m_WholeObject != null)
            m_WholeObject.SetActive(false);

        // 激活所有碎片并施加爆炸力
        foreach (var fragment in m_Fragments)
        {
            if (fragment == null) continue;
            
            fragment.SetActive(true);
            
            var rb = fragment.GetComponent<Rigidbody>();
            if (rb != null)
            {
                rb.isKinematic = false;
                rb.AddExplosionForce(force, explosionCenter, m_ExplosionRadius, 0.5f, ForceMode.Impulse);
                rb.AddTorque(Random.insideUnitSphere * force * 0.3f, ForceMode.Impulse);
            }
            
            Destroy(fragment, m_FragmentLifetime);
        }
    }

    /// <summary>
    /// 外部碰撞触发
    /// </summary>
    void OnCollisionEnter(Collision collision)
    {
        if (collision.relativeVelocity.magnitude > 5f)
            Break(collision.contacts[0].point, collision.relativeVelocity.magnitude);
    }
```

## 七、最佳实践总结

### 7.1 算法选型指南

1. **单刀切割（剑气、激光）** → 使用平面切割算法，效果精确、性能可控
2. **爆炸破碎** → 优先Voronoi预计算，运行时性能最优
3. **弹射穿透** → 考虑使用Decal系统模拟弹孔，避免真实几何切割
4. **复杂任意形切割** → 接入专业插件（DinoFracture、NvBlast）

### 7.2 性能控制要点

1. **严格限制每帧切割次数**：建议每帧不超过2次完整切割
2. **碎片数量上限管理**：全局维护活跃碎片计数器，超额时移除最旧碎片
3. **凸包Collider替代精确Mesh Collider**：碎片使用`convex=true`，减少物理计算开销
4. **LOD策略**：远距离碎片降级为简化Mesh或直接隐藏

### 7.3 视觉优化原则

1. **截面材质设计**：截面材质应使用独立的tiling UV，避免与原始纹理坐标冲突
2. **切割特效掩盖延迟**：在切割计算期间用粒子特效掩盖短暂的处理延迟
3. **碎片运动阻尼**：合理设置`drag`和`angularDrag`，让碎片运动符合质感预期
4. **碎片渐隐销毁**：碎片消亡前播放渐隐动画，避免突然消失的突兀感

### 7.4 工程化建议

1. **预计算优于运行时计算**：关键游戏对象在制作阶段预处理破碎，运行时仅触发
2. **碎片预热对象池**：游戏启动时预创建碎片对象，避免运行时实例化开销
3. **切割状态持久化**：多人游戏中需要同步切割状态到所有客户端
4. **内存清理策略**：定期清理`Mesh.vertices`等托管堆数组，防止内存持续增长

---

> **总结**：实时网格切割是游戏物理破坏系统的核心技术，核心挑战在于平衡视觉效果与运行时性能。平面切割算法在数学上严谨且工程可控，而Voronoi预计算破碎则在保证视觉效果的同时将运行时开销压到最低。在实际项目中，两种方案往往结合使用：主要破坏效果用预计算，精确切割互动用实时算法。
