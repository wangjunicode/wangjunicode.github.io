# 游戏程序化叙事系统完全指南：从文本模板到动态剧情分支引擎

## 前言：为什么程序化叙事正在成为游戏开发的必选项

传统游戏叙事依赖"手工编写全部对话"——一个大型RPG可能包含数十万字的精心设计台词。然而，当游戏向更大规模迈进时，这种方式面临根本性挑战：

- **Roguelike/Roguelite游戏**：每次游玩要求不同的世界背景和NPC反应
- **开放世界游戏**：数千个NPC需要对玩家行为做出合理的情境化响应
- **AI生成内容时代**：玩家期望NPC能"记住"发生过的事情，而非说固定台词

**程序化叙事（Procedural Narrative）**不是随机生成对话，而是**基于规则、状态和上下文，自动组合生成有意义的叙事内容**。

本文将从工程视角，构建一套完整的程序化叙事系统，包括：对话脚本语言集成、叙事知识库、情境感知引擎、以及与AI大模型的结合方案。

## 二、对话脚本语言设计

### 2.1 自研轻量级叙事脚本（NarScript）

对于不需要引入完整Ink/Yarn体量的项目，一个轻量级自研脚本语言更灵活：

```
// NarScript 语法示例：merchant_greeting.nar
// 场景：玩家第一次进入商店

[START]
    // 条件判断
    IF {player.visitCount} == 0
        -> FIRST_VISIT
    ELSE IF {player.reputation} >= 80
        -> TRUSTED_CUSTOMER
    ELSE
        -> REGULAR_VISIT

[FIRST_VISIT]
    NPC: 欢迎光临，旅行者！看来你是第一次来到{world.cityName}？
    CHOICE:
        - "是的，我刚到这里。"
            -> EXPLAIN_CITY
        - "只是路过，看看有什么好货。"
            -> SHOW_WARES
        - [CONDITION: player.hasMap == false] "能给我看看地图吗？"
            -> OFFER_MAP

[EXPLAIN_CITY]
    NPC: {world.cityName}是一座有着{world.cityAge}年历史的古城。
    NPC: 如果你需要装备，我这里应有尽有！
    SET player.visitCount += 1
    SET player.knowsCityHistory = true
    -> SHOW_WARES

[OFFER_MAP]
    NPC: 当然！不过地图需要{items.map.price}金币。
    CHOICE:
        - [CONDITION: player.gold >= items.map.price] "好，我买了。"
            -> BUY_MAP
        - "太贵了，算了。"
            -> SHOW_WARES

[BUY_MAP]
    NPC: 这是{world.cityName}及周边地区的详细地图，祝你旅途愉快！
    ADD_ITEM player.inventory: map_city_{world.cityId}
    REMOVE_GOLD player: {items.map.price}
    -> SHOW_WARES

[SHOW_WARES]
    NPC: 来看看我的商品吧！
    OPEN_SHOP
    -> END

[TRUSTED_CUSTOMER]
    NPC: {player.name}！我的老客户！今天有什么需要？
    NPC: 作为VIP客户，你享受九折优惠。
    SET player.currentDiscount = 0.9
    -> SHOW_WARES

[REGULAR_VISIT]
    NPC: 欢迎！需要什么尽管开口。
    -> SHOW_WARES

[END]
```

### 2.2 NarScript解析器实现

```csharp
using System;
using System.Collections.Generic;
using System.Text.RegularExpressions;
using UnityEngine;

/// <summary>
/// NarScript词法单元类型
/// </summary>
public enum TokenType
{
    Label,          // [LABEL_NAME]
    NpcLine,        // NPC: 文本内容
    PlayerLine,     // PLAYER: 文本内容
    Choice,         // CHOICE:
    ChoiceOption,   // - 选项文本
    Goto,           // -> LABEL
    If,             // IF {condition}
    ElseIf,         // ELSE IF {condition}
    Else,           // ELSE
    Set,            // SET variable = value
    Condition,      // [CONDITION: expr]
    Command,        // ADD_ITEM, OPEN_SHOP etc.
    Comment,        // // 注释
    End             // -> END
}

public class NarToken
{
    public TokenType Type;
    public string Value;
    public int LineNumber;
    
    public override string ToString() => $"[{Type}] {Value} (line {LineNumber})";
}

/// <summary>
/// 对话节点（解析后的AST节点）
/// </summary>
public abstract class DialogueNode
{
    public abstract void Accept(IDialogueNodeVisitor visitor);
}

public class LabelNode : DialogueNode
{
    public string Name;
    public List<DialogueNode> Children = new();
    public override void Accept(IDialogueNodeVisitor visitor) => visitor.VisitLabel(this);
}

public class SpeechNode : DialogueNode
{
    public string Speaker;  // "NPC" 或 NPC名称
    public string Text;
    public override void Accept(IDialogueNodeVisitor visitor) => visitor.VisitSpeech(this);
}

public class ChoiceNode : DialogueNode
{
    public List<ChoiceOption> Options = new();
    public override void Accept(IDialogueNodeVisitor visitor) => visitor.VisitChoice(this);
}

public class ChoiceOption
{
    public string Text;
    public string Condition; // 可选条件表达式
    public string GotoLabel;
}

public class GotoNode : DialogueNode
{
    public string TargetLabel;
    public override void Accept(IDialogueNodeVisitor visitor) => visitor.VisitGoto(this);
}

public class ConditionNode : DialogueNode
{
    public string Condition;
    public List<DialogueNode> ThenBranch = new();
    public List<DialogueNode> ElseBranch = new();
    public override void Accept(IDialogueNodeVisitor visitor) => visitor.VisitCondition(this);
}

public class SetVariableNode : DialogueNode
{
    public string VariablePath;
    public string Operator; // =, +=, -=
    public string ValueExpression;
    public override void Accept(IDialogueNodeVisitor visitor) => visitor.VisitSetVariable(this);
}

public class CommandNode : DialogueNode
{
    public string CommandName;
    public List<string> Arguments = new();
    public override void Accept(IDialogueNodeVisitor visitor) => visitor.VisitCommand(this);
}

public interface IDialogueNodeVisitor
{
    void VisitLabel(LabelNode node);
    void VisitSpeech(SpeechNode node);
    void VisitChoice(ChoiceNode node);
    void VisitGoto(GotoNode node);
    void VisitCondition(ConditionNode node);
    void VisitSetVariable(SetVariableNode node);
    void VisitCommand(CommandNode node);
}

/// <summary>
/// NarScript词法分析器
/// </summary>
public class NarScriptLexer
{
    private static readonly Regex LabelRegex = new(@"^\[([A-Z_]+)\]$");
    private static readonly Regex NpcLineRegex = new(@"^([A-Z_\u4e00-\u9fa5]+):\s*(.+)$");
    private static readonly Regex GotoRegex = new(@"^->\s*(.+)$");
    private static readonly Regex IfRegex = new(@"^IF\s+(.+)$");
    private static readonly Regex ElseIfRegex = new(@"^ELSE IF\s+(.+)$");
    private static readonly Regex SetRegex = new(@"^SET\s+(.+?)\s*([+\-]?=)\s*(.+)$");
    private static readonly Regex ChoiceOptionRegex = new(@"^-\s+(\[CONDITION:\s*(.+?)\]\s*)?(.+)$");
    
    public List<NarToken> Tokenize(string script)
    {
        var tokens = new List<NarToken>();
        var lines = script.Split('\n');
        
        for (int i = 0; i < lines.Length; i++)
        {
            string line = lines[i].Trim();
            int lineNum = i + 1;
            
            if (string.IsNullOrEmpty(line) || line.StartsWith("//"))
                continue;
            
            Match m;
            
            if ((m = LabelRegex.Match(line)).Success)
                tokens.Add(new NarToken { Type = TokenType.Label, Value = m.Groups[1].Value, LineNumber = lineNum });
            else if (line == "CHOICE:")
                tokens.Add(new NarToken { Type = TokenType.Choice, Value = "", LineNumber = lineNum });
            else if ((m = ChoiceOptionRegex.Match(line)).Success)
            {
                string condition = m.Groups[2].Value;
                string text = m.Groups[3].Value;
                // 解析 -> GOTO
                var gotoMatch = Regex.Match(text, @"^(.+?)\s*\[GOTO:\s*(.+?)\]$");
                tokens.Add(new NarToken 
                { 
                    Type = TokenType.ChoiceOption, 
                    Value = string.IsNullOrEmpty(condition) ? text : $"{condition}|{text}",
                    LineNumber = lineNum 
                });
            }
            else if ((m = GotoRegex.Match(line)).Success)
                tokens.Add(new NarToken { Type = TokenType.Goto, Value = m.Groups[1].Value, LineNumber = lineNum });
            else if ((m = IfRegex.Match(line)).Success)
                tokens.Add(new NarToken { Type = TokenType.If, Value = m.Groups[1].Value, LineNumber = lineNum });
            else if ((m = ElseIfRegex.Match(line)).Success)
                tokens.Add(new NarToken { Type = TokenType.ElseIf, Value = m.Groups[1].Value, LineNumber = lineNum });
            else if (line == "ELSE")
                tokens.Add(new NarToken { Type = TokenType.Else, Value = "", LineNumber = lineNum });
            else if ((m = SetRegex.Match(line)).Success)
                tokens.Add(new NarToken { Type = TokenType.Set, Value = line, LineNumber = lineNum });
            else if ((m = NpcLineRegex.Match(line)).Success)
                tokens.Add(new NarToken { Type = TokenType.NpcLine, Value = line, LineNumber = lineNum });
            else
                tokens.Add(new NarToken { Type = TokenType.Command, Value = line, LineNumber = lineNum });
        }
        
        return tokens;
    }
}
```

## 三、世界状态模型（World Model）

程序化叙事的核心是"感知上下文"——NPC需要了解世界的当前状态才能做出合适的回应。

### 3.1 叙事知识库设计

```csharp
/// <summary>
/// 叙事世界模型：存储所有可影响对话的状态
/// </summary>
public class NarrativeWorldModel
{
    // 玩家状态
    public PlayerState Player { get; set; } = new();
    
    // 世界/场景状态
    public WorldState World { get; set; } = new();
    
    // NPC关系网络
    public Dictionary<string, NpcRelationship> NpcRelationships { get; set; } = new();
    
    // 全局事件历史（影响叙事的关键事件）
    public List<NarrativeEvent> EventHistory { get; set; } = new();
    
    // 当前对话中NPC的情感状态
    public Dictionary<string, EmotionalState> NpcEmotions { get; set; } = new();
    
    /// <summary>
    /// 通过路径表达式获取值（支持 player.level, world.timeOfDay 等）
    /// </summary>
    public object GetValue(string path)
    {
        var parts = path.Split('.');
        object current = this;
        
        foreach (var part in parts)
        {
            if (current == null) return null;
            
            // 反射访问属性
            var type = current.GetType();
            var prop = type.GetProperty(
                char.ToUpper(part[0]) + part[1..],
                System.Reflection.BindingFlags.Public | 
                System.Reflection.BindingFlags.Instance |
                System.Reflection.BindingFlags.IgnoreCase);
            
            if (prop != null)
            {
                current = prop.GetValue(current);
                continue;
            }
            
            // 字典访问
            if (current is IDictionary<string, object> dict)
            {
                current = dict.TryGetValue(part, out var val) ? val : null;
                continue;
            }
            
            return null;
        }
        
        return current;
    }
    
    public void SetValue(string path, object value)
    {
        var parts = path.Split('.');
        object current = this;
        
        for (int i = 0; i < parts.Length - 1; i++)
        {
            var type = current.GetType();
            var prop = type.GetProperty(
                char.ToUpper(parts[i][0]) + parts[i][1..],
                System.Reflection.BindingFlags.Public | 
                System.Reflection.BindingFlags.Instance | 
                System.Reflection.BindingFlags.IgnoreCase);
            if (prop != null)
                current = prop.GetValue(current);
        }
        
        string lastPart = parts[^1];
        var finalType = current.GetType();
        var finalProp = finalType.GetProperty(
            char.ToUpper(lastPart[0]) + lastPart[1..],
            System.Reflection.BindingFlags.Public | 
            System.Reflection.BindingFlags.Instance | 
            System.Reflection.BindingFlags.IgnoreCase);
        
        if (finalProp != null && finalProp.CanWrite)
        {
            object convertedValue = Convert.ChangeType(value, finalProp.PropertyType);
            finalProp.SetValue(current, convertedValue);
        }
    }
    
    /// <summary>
    /// 记录叙事事件（NPC会记住这些事件）
    /// </summary>
    public void RecordEvent(string eventType, string subject, string detail = null, 
                            string location = null)
    {
        EventHistory.Add(new NarrativeEvent
        {
            EventType = eventType,
            Subject = subject,
            Detail = detail,
            Location = location ?? World.CurrentLocation,
            Timestamp = DateTime.UtcNow,
            GameTime = World.GameTime
        });
        
        // 只保留最近1000条事件（避免无限增长）
        if (EventHistory.Count > 1000)
            EventHistory.RemoveAt(0);
    }
    
    /// <summary>
    /// 查询特定类型的历史事件
    /// </summary>
    public List<NarrativeEvent> QueryEvents(string eventType, string subject = null, 
                                            int maxCount = 10)
    {
        var query = EventHistory.Where(e => e.EventType == eventType);
        if (subject != null)
            query = query.Where(e => e.Subject == subject);
        return query.TakeLast(maxCount).ToList();
    }
}

{
    public string Id { get; set; }
    public string Name { get; set; }
    public int Level { get; set; }
    public long Gold { get; set; }
    public int Reputation { get; set; }       // 全局声誉 0-100
    public string Faction { get; set; }       // 所属势力
    public Dictionary<string, bool> Flags { get; set; } = new(); // 剧情标记
    public Dictionary<string, int> Variables { get; set; } = new(); // 数值变量

{
    public string CityName { get; set; }
    public int CityAge { get; set; }
    public string CityId { get; set; }
    public string TimeOfDay { get; set; } // "morning", "afternoon", "evening", "night"
    public string Season { get; set; }
    public string Weather { get; set; }
    public string CurrentLocation { get; set; }
    public DateTime GameTime { get; set; }
    public Dictionary<string, bool> WorldFlags { get; set; } = new();

    public int Affinity { get; set; }       // 好感度 -100 to 100
    public bool HasMet { get; set; }
    public int ConversationCount { get; set; }
    public List<string> SharedHistory { get; set; } = new(); // 共同经历的事件ID
    public Dictionary<string, bool> NpcKnowledge { get; set; } = new(); // NPC知道的事

{
    public string EventType { get; set; }
    public string Subject { get; set; }
    public string Detail { get; set; }
    public string Location { get; set; }
    public DateTime Timestamp { get; set; }
    public DateTime GameTime { get; set; }

public class EmotionalState
{
    public float Joy { get; set; }     // 0-1
    public float Anger { get; set; }   // 0-1
    public float Fear { get; set; }    // 0-1
    public float Sadness { get; set; } // 0-1
    public float Trust { get; set; }   // 0-1
    
    public string DominantEmotion => GetDominantEmotion();
    
    private string GetDominantEmotion()
    {
        var emotions = new Dictionary<string, float>
        {
            ["Joy"] = Joy, ["Anger"] = Anger, 
            ["Fear"] = Fear, ["Sadness"] = Sadness, ["Trust"] = Trust
        };
        return emotions.OrderByDescending(e => e.Value).First().Key;
    }
}
```

## 四、情境感知条件表达式评估器

NarScript中的条件（如 `{player.level} >= 10`）需要一个完整的表达式评估器：

```csharp
/// <summary>
/// 叙事条件表达式评估器
/// 支持：比较运算符、逻辑运算符、字符串操作、历史事件查询
/// </summary>
public class NarrativeConditionEvaluator
{
    private readonly NarrativeWorldModel _worldModel;
    
    // 变量引用正则：匹配 {player.level} 或 {world.timeOfDay}
    private static readonly Regex VariableRegex = new(@"\{([^}]+)\}");
    
    public NarrativeConditionEvaluator(NarrativeWorldModel worldModel)
    {
        _worldModel = worldModel;
    }
    
    /// <summary>
    /// 评估条件表达式
    /// </summary>
    public bool Evaluate(string condition)
    {
        if (string.IsNullOrWhiteSpace(condition)) return true;
        
        condition = condition.Trim();
        
        // 处理逻辑 AND（&&）
        if (condition.Contains(" && "))
        {
            var parts = SplitByOperator(condition, " && ");
            return parts.All(p => Evaluate(p));
        }
        
        // 处理逻辑 OR（||）
        if (condition.Contains(" || "))
        {
            var parts = SplitByOperator(condition, " || ");
            return parts.Any(p => Evaluate(p));
        }
        
        // 处理逻辑 NOT
        if (condition.StartsWith("NOT ") || condition.StartsWith("!"))
        {
            string inner = condition.StartsWith("NOT ") ? condition[4..] : condition[1..];
            return !Evaluate(inner.Trim());
        }
        
        // 处理特殊函数
        if (condition.StartsWith("HAS_COMPLETED_QUEST("))
        {
            string questId = ExtractFunctionArg(condition, "HAS_COMPLETED_QUEST");
            return _worldModel.Player.CompletedQuests.Contains(questId);
        }
        
        if (condition.StartsWith("HAS_ITEM("))
        {
            string itemId = ExtractFunctionArg(condition, "HAS_ITEM");
            return CheckPlayerHasItem(itemId);
        }
        
        if (condition.StartsWith("HAS_EVENT("))
        {
            string[] args = ExtractFunctionArgs(condition, "HAS_EVENT");
            string eventType = args[0];
            string subject = args.Length > 1 ? args[1] : null;
            return _worldModel.QueryEvents(eventType, subject, 1).Count > 0;
        }
        
        if (condition.StartsWith("KNOWS("))
        {
            // 检查NPC是否知道某件事
            string[] args = ExtractFunctionArgs(condition, "KNOWS");
            if (args.Length >= 2)
            {
                string npcId = args[0];
                string knowledge = args[1];
                if (_worldModel.NpcRelationships.TryGetValue(npcId, out var rel))
                    return rel.NpcKnowledge.TryGetValue(knowledge, out bool val) && val;
            }
            return false;
        }
        
        // 处理比较运算符
        return EvaluateComparison(condition);
    }
    
    private bool EvaluateComparison(string expr)
    {
        // 支持的操作符（按长度降序检测，避免 >= 被误匹配为 >）
        string[] operators = { ">=", "<=", "!=", "==", ">", "<", "CONTAINS", "IN" };
        
        foreach (var op in operators)
        {
            int opIdx = expr.IndexOf($" {op} ", StringComparison.OrdinalIgnoreCase);
            if (opIdx < 0) continue;
            
            string leftExpr = expr[..opIdx].Trim();
            string rightExpr = expr[(opIdx + op.Length + 2)..].Trim();
            
            object leftValue = ResolveValue(leftExpr);
            object rightValue = ResolveValue(rightExpr);
            
            return Compare(leftValue, rightValue, op);
        }
        
        // 单独的布尔值或变量
        object val = ResolveValue(expr);
        if (val is bool b) return b;
        if (val is string s) return !string.IsNullOrEmpty(s) && s != "false" && s != "0";
        if (val is int i) return i != 0;
        if (val is float f) return f != 0;
        return val != null;
    }
    
    /// <summary>
    /// 解析值：变量引用、字面量（字符串、数字、布尔）
    /// </summary>
    private object ResolveValue(string expr)
    {
        expr = expr.Trim();
        
        // 字符串字面量
        if (expr.StartsWith("\"") && expr.EndsWith("\""))
            return expr[1..^1];
        
        // 数字字面量
        if (float.TryParse(expr, out float f)) return f;
        if (int.TryParse(expr, out int i)) return i;
        
        // 布尔字面量
        if (expr.Equals("true", StringComparison.OrdinalIgnoreCase)) return true;
        if (expr.Equals("false", StringComparison.OrdinalIgnoreCase)) return false;
        
        // 变量引用（带大括号或不带）
        string varPath = VariableRegex.Match(expr).Success 
            ? VariableRegex.Match(expr).Groups[1].Value 
            : expr;
        
        return _worldModel.GetValue(varPath);
    }
    
    private bool Compare(object left, object right, string op)
    {
        // 尝试数值比较
        if (TryGetNumeric(left, out double l) && TryGetNumeric(right, out double r))
        {
            return op switch
            {
                ">=" => l >= r, "<=" => l <= r,
                "!=" => Math.Abs(l - r) > 1e-9,
                "==" => Math.Abs(l - r) <= 1e-9,
                ">" => l > r, "<" => l < r,
                _ => false
            };
        }
        
        // 字符串比较
        string ls = left?.ToString() ?? "";
        string rs = right?.ToString() ?? "";
        
        return op switch
        {
            "==" => ls.Equals(rs, StringComparison.OrdinalIgnoreCase),
            "!=" => !ls.Equals(rs, StringComparison.OrdinalIgnoreCase),
            "CONTAINS" => ls.Contains(rs, StringComparison.OrdinalIgnoreCase),
            _ => false
        };
    }
    
    private static bool TryGetNumeric(object value, out double result)
    {
        if (value is double d) { result = d; return true; }
        if (value is float f) { result = f; return true; }
        if (value is int i) { result = i; return true; }
        if (value is long l) { result = l; return true; }
        if (value != null && double.TryParse(value.ToString(), out result)) return true;
        result = 0;
        return false;
    }
    
    private string ExtractFunctionArg(string expr, string funcName)
    {
        int start = expr.IndexOf('(') + 1;
        int end = expr.LastIndexOf(')');
        return expr[start..end].Trim().Trim('"');
    }
    
    private string[] ExtractFunctionArgs(string expr, string funcName)
    {
        string argsStr = ExtractFunctionArg(expr, funcName);
        return argsStr.Split(',').Select(s => s.Trim().Trim('"')).ToArray();
    }
    
    private List<string> SplitByOperator(string expr, string op)
    {
        // 简单分割（不考虑括号内的操作符，实际项目需完整处理）
        return expr.Split(new[] { op }, StringSplitOptions.None).ToList();
    }
    
    private bool CheckPlayerHasItem(string itemId)
    {
        // 委托给背包系统检查
        return InventoryManager.Instance?.HasItem(itemId) ?? false;
    }
}
```

## 五、动态文本替换与本地化感知

脚本中的 `{player.name}`、`{world.cityName}` 等需要在运行时替换为实际值：

```csharp
/// <summary>
/// 叙事文本变量替换器
/// 支持：变量插值、格式化、条件嵌入
/// </summary>
public class NarrativeTextSubstitutor
{
    private readonly NarrativeWorldModel _worldModel;
    private readonly NarrativeConditionEvaluator _condEvaluator;
    
    // 简单变量：{player.name}
    private static readonly Regex SimpleVarRegex = new(@"\{([^|{}]+)\}");
    
    // 条件嵌入：{IF condition|true_text|false_text}
    private static readonly Regex ConditionalRegex = new(@"\{IF ([^|]+)\|([^|]*)\|([^}]*)\}");
    
    // 格式化：{player.gold:N0} → 1,234
    private static readonly Regex FormattedVarRegex = new(@"\{([^:}]+):([^}]+)\}");
    
    // 复数形式：{count} {count:PLURAL|item|items}
    private static readonly Regex PluralRegex = new(@"\{([^:}]+):PLURAL\|([^|]+)\|([^}]+)\}");
    
    public NarrativeTextSubstitutor(
        NarrativeWorldModel worldModel, 
        NarrativeConditionEvaluator condEvaluator)
    {
        _worldModel = worldModel;
        _condEvaluator = condEvaluator;
    }
    
    public string Substitute(string template)
    {
        if (string.IsNullOrEmpty(template)) return template;
        
        // 处理条件嵌入（优先）
        template = ConditionalRegex.Replace(template, match =>
        {
            string condition = match.Groups[1].Value;
            string trueText = match.Groups[2].Value;
            string falseText = match.Groups[3].Value;
            return _condEvaluator.Evaluate(condition) ? trueText : falseText;
        });
        
        // 处理复数
        template = PluralRegex.Replace(template, match =>
        {
            string varPath = match.Groups[1].Value;
            string singular = match.Groups[2].Value;
            string plural = match.Groups[3].Value;
            object val = _worldModel.GetValue(varPath);
            if (TryGetNumeric(val, out double num))
                return Math.Abs(num - 1) < 1e-9 ? singular : plural;
            return plural;
        });
        
        // 处理格式化变量
        template = FormattedVarRegex.Replace(template, match =>
        {
            string varPath = match.Groups[1].Value;
            string format = match.Groups[2].Value;
            object val = _worldModel.GetValue(varPath);
            return FormatValue(val, format);
        });
        
        // 处理简单变量
        template = SimpleVarRegex.Replace(template, match =>
        {
            string varPath = match.Groups[1].Value;
            object val = _worldModel.GetValue(varPath);
            return val?.ToString() ?? $"[{varPath}]";
        });
        
        return template;
    }
    
    private string FormatValue(object value, string format)
    {
        if (value == null) return "";
        
        return format.ToUpper() switch
        {
            "N0" => Convert.ToDouble(value).ToString("N0"),
            "N1" => Convert.ToDouble(value).ToString("N1"),
            "N2" => Convert.ToDouble(value).ToString("N2"),
            "P0" => (Convert.ToDouble(value) / 100).ToString("P0"),
            "UPPER" => value.ToString().ToUpper(),
            "LOWER" => value.ToString().ToLower(),
            "DATE" => Convert.ToDateTime(value).ToString("yyyy-MM-dd"),
            _ => value.ToString()
        };
    }
    
    private static bool TryGetNumeric(object value, out double result)
    {
        if (value is double d) { result = d; return true; }
        if (value is float f) { result = f; return true; }
        if (value is int i) { result = i; return true; }
        result = 0;
        return double.TryParse(value?.ToString(), out result);
    }
}
```

## 六、程序化对话生成：基于规则引擎

当静态对话树无法覆盖所有情境时，**规则引擎**可以动态选择最合适的对话片段：

```csharp
/// <summary>
/// 叙事规则：定义在什么条件下选择什么对话片段
/// </summary>
public class NarrativeRule
{
    public string Id { get; set; }
    public string Category { get; set; }    // 规则分类：greeting/comment/reaction
    public int Priority { get; set; }       // 优先级（值越高越优先）
    public string Condition { get; set; }   // 触发条件
    public List<string> Texts { get; set; } = new(); // 候选文本（随机选一条）
    public string SpeakerEmotion { get; set; }       // 说这句话时NPC的情感
    public Dictionary<string, string> Effects { get; set; } = new(); // 说完后的效果
    
    // 冷却：避免NPC一直重复同一句话
    public int CooldownSeconds { get; set; } = 30;
    public DateTime LastUsedTime { get; set; } = DateTime.MinValue;
    
    public bool IsOnCooldown => 
        (DateTime.UtcNow - LastUsedTime).TotalSeconds < CooldownSeconds;
}

/// <summary>
/// 程序化对话选择器：基于规则引擎动态选择对话
/// </summary>
public class ProceduralDialogueSelector
{
    private readonly List<NarrativeRule> _rules;
    private readonly NarrativeConditionEvaluator _evaluator;
    private readonly NarrativeTextSubstitutor _substitutor;
    private readonly Random _random = new();
    
    public ProceduralDialogueSelector(
        List<NarrativeRule> rules,
        NarrativeConditionEvaluator evaluator,
        NarrativeTextSubstitutor substitutor)
    {
        _rules = rules;
        _evaluator = evaluator;
        _substitutor = substitutor;
    }
    
    /// <summary>
    /// 选择最合适的对话片段
    /// </summary>
    public DialogueFragment SelectBestDialogue(string category, int maxResults = 1)
    {
        // 1. 过滤：类别匹配 + 条件满足 + 不在冷却中
        var eligibleRules = _rules
            .Where(r => r.Category == category)
            .Where(r => !r.IsOnCooldown)
            .Where(r => _evaluator.Evaluate(r.Condition))
            .OrderByDescending(r => r.Priority)
            .ToList();
        
        if (eligibleRules.Count == 0) return null;
        
        // 2. 从最高优先级的候选中随机选（优先级相同的随机）
        int maxPriority = eligibleRules[0].Priority;
        var topRules = eligibleRules.TakeWhile(r => r.Priority == maxPriority).ToList();
        var selectedRule = topRules[_random.Next(topRules.Count)];
        
        // 3. 从该规则的候选文本中随机选一条
        string rawText = selectedRule.Texts[_random.Next(selectedRule.Texts.Count)];
        string finalText = _substitutor.Substitute(rawText);
        
        // 4. 更新冷却
        selectedRule.LastUsedTime = DateTime.UtcNow;
        
        return new DialogueFragment
        {
            Text = finalText,
            Emotion = selectedRule.SpeakerEmotion ?? "neutral",
            Effects = selectedRule.Effects,
            RuleId = selectedRule.Id
        };
    }
    
    /// <summary>
    /// 生成NPC的动态打招呼语（基于时间、天气、玩家状态等）
    /// </summary>
    public List<DialogueFragment> GenerateContextualGreeting(
        string npcId, string npcPersonality)
    {
        var fragments = new List<DialogueFragment>();
        
        // 主问候语
        var greeting = SelectBestDialogue($"greeting_{npcPersonality}");
        if (greeting != null) fragments.Add(greeting);
        
        // 附加评论（基于当前情境）
        var contextComment = SelectBestDialogue("context_comment");
        if (contextComment != null) fragments.Add(contextComment);
        
        // 引导到主要对话选项
        var transition = SelectBestDialogue("greeting_transition");
        if (transition != null) fragments.Add(transition);
        
        return fragments;
    }
}

public class DialogueFragment
{
    public string Text { get; set; }
    public string Emotion { get; set; }
    public Dictionary<string, string> Effects { get; set; } = new();
    public string RuleId { get; set; }
}
```

## 七、与大语言模型（LLM）的集成方案

现代程序化叙事系统的终极形态是结合LLM，实现真正的动态对话：

```csharp
/// <summary>
/// LLM驱动的NPC对话生成器
/// 使用结构化Prompt确保输出符合游戏叙事规范
/// </summary>
public class LLMNarrativeGenerator
{
    private readonly ILLMClient _llmClient;
    private readonly NarrativeWorldModel _worldModel;
    
    public LLMNarrativeGenerator(ILLMClient llmClient, NarrativeWorldModel worldModel)
    {
        _llmClient = llmClient;
        _worldModel = worldModel;
    }
    
    /// <summary>
    /// 为NPC生成情境响应
    /// </summary>
    public async Task<string> GenerateNpcResponseAsync(
        NpcProfile npc, string playerInput, 
        CancellationToken ct = default)
    {
        // 构建结构化System Prompt
        string systemPrompt = BuildNpcSystemPrompt(npc);
        string contextPrompt = BuildContextPrompt(npc.Id);
        
        string fullPrompt = $"""
            {systemPrompt}
            
            ## 当前情境
            {contextPrompt}
            
            ## 对话历史
            （此处可添加最近N条对话历史）
            
            ## 玩家说：{playerInput}
            
            请用不超过50字，以{npc.Name}的身份回应。
            只返回NPC说的话，不要包含任何描述或注释。
            """;
        
        return await _llmClient.GenerateAsync(fullPrompt, maxTokens: 100, ct);
    }
    
    private string BuildNpcSystemPrompt(NpcProfile npc)
    {
        return $"""
            你是{npc.Name}，一个{npc.Role}。
            性格特点：{string.Join("、", npc.PersonalityTraits)}
            说话风格：{npc.SpeechStyle}
            价值观：{npc.Values}
            
            规则：
            1. 始终保持角色一致性，不要出戏
            2. 考虑你对玩家的了解和感受（好感度：{GetAffinity(npc.Id)}）
            3. 语言符合世界观（{_worldModel.World.CityName}，{_worldModel.World.Season}时节）
            4. 不透露游戏机制信息（如"好感度"数值）
            """;
    }
    
    private string BuildContextPrompt(string npcId)
    {
        var player = _worldModel.Player;
        var world = _worldModel.World;
        var recentEvents = _worldModel.QueryEvents("", null, 5);
        
        var sb = new System.Text.StringBuilder();
        sb.AppendLine($"时间：{world.TimeOfDay}，{world.Weather}天气");
        sb.AppendLine($"地点：{world.CurrentLocation}");
        sb.AppendLine($"玩家：{player.Name}，等级{player.Level}，声誉{player.Reputation}");
        
        if (recentEvents.Count > 0)
        {
            sb.AppendLine("近期发生的重要事件：");
            foreach (var evt in recentEvents.TakeLast(3))
                sb.AppendLine($"  - {evt.EventType}: {evt.Detail}");
        }
        
        return sb.ToString();
    }
    
    private int GetAffinity(string npcId)
    {
        return _worldModel.NpcRelationships.TryGetValue(npcId, out var rel) 
            ? rel.Affinity : 0;
    }
}

public class NpcProfile
{
    public string Id { get; set; }
    public string Name { get; set; }
    public string Role { get; set; }
    public List<string> PersonalityTraits { get; set; } = new();
    public string SpeechStyle { get; set; }
    public string Values { get; set; }
}

public interface ILLMClient
{
    Task<string> GenerateAsync(string prompt, int maxTokens = 200, 
                               CancellationToken ct = default);
}
```

## 八、最佳实践总结

### 叙事系统设计原则

1. **状态驱动，而非硬编码**：任何影响对话的因素都应建模为WorldModel中的状态
2. **分层设计**：脚本层（编剧）→ 规则层（设计师）→ LLM层（动态补充），各层职责清晰
3. **冷却机制**：避免NPC反复说同一句话，用冷却时间保证对话新鲜感
4. **事件历史**：NPC"记住"玩家的行为，是沉浸感的关键
5. **优雅降级**：LLM不可用时降级到规则引擎，规则引擎无结果时降级到默认脚本

### 内容管线建议

```
策划设计阶段：
    Excel/表格 → NarScript 脚本
        ↓
工具链转换：
    NarScript → AST → 二进制（运行时格式）
        ↓
运行时加载：
    二进制 → NarrativeEngine（条件评估 + 文本替换）
        ↓
LLM辅助：
    对于复杂自由对话场景 → 调用LLM API，结果缓存30分钟
```

### 性能优化要点

```csharp
// 预编译条件表达式为委托（避免运行时反射）
// 生产项目中应将 "player.level >= 10" 预编译为：
Func<NarrativeWorldModel, bool> compiledCondition = 
    model => model.Player.Level >= 10;

// 对话资源按场景懒加载（不要一次性加载所有NarScript文件）
// LLM响应结果缓存（相同情境+玩家输入 → 缓存响应30分钟）
// 异步预生成（在玩家接近NPC时提前生成可能的欢迎语）
```
